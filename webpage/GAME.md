# DEBUT : ON

React + TypeScript + Three.js로 만든 한국어 WebGL 아이돌 성장 보드게임. 기본 경로 `/`에서 실행합니다.

## 실행

```sh
npm install
npm run dev -- --port 5175 --strictPort
```

브라우저에서 http://localhost:5175 를 엽니다. `npm run build`로 배포용 `dist/`를 생성합니다. 현재 실행 중인 다른 프로젝트가 있으면 포트를 달리 사용하세요.

## 플레이

- 기본 구성: 사람 1명 + AI 3명. **새 게임**에서 총 1~4명, 사람 수, 캐릭터, 이름, 목표 점수(300/400/600P)를 설정합니다.
- 같은 기기에서 차례로 조작하는 로컬 멀티플레이입니다. 인터넷을 통한 원격 멀티플레이 서버는 포함하지 않습니다.
- 주사위를 클릭하거나 보드 화면의 빈 곳에 포커스한 상태에서 Space를 눌러 1~6칸 이동합니다. 한 바퀴를 돌면 20P를 받습니다.
- 기획사에서 보컬·댄스·랩 미니게임으로 점수, 경험치, 능력치를 획득합니다. 무대 칸은 추가 점수를, 행운 칸은 무작위 보상을 줍니다.
- 보컬: 바늘이 가운데일 때 Space 또는 버튼, 총 5회.
- 댄스: 화면에 표시된 방향키 또는 터치 버튼, 총 8회.
- 랩: 표시된 시간(0.45~0.85초)만큼 Space 또는 버튼을 눌렀다 놓기, 총 5회.
- 미니게임은 시작 후 16초가 지나면 자동 종료합니다. 완료하지 않은 시도는 0점이며, 참여한 연습에는 기본 보상을 줍니다.
- 도착한 칸에 참가자가 있으면 기획사 활동 후 배틀합니다. 도전자가 장르를 선택하고 두 참가자가 순서대로 조작합니다. 능력치 55% + 미니게임 45%로 판정하며 승자 +45P, 패자 +10P, 무승부 각각 +25P입니다. 같은 칸의 다른 참가자 모두와 차례대로 배틀합니다.
- 전원이 한 번씩 차례를 마치면 1라운드입니다. 4라운드마다 월말 평가를 진행합니다.
- 월말 평가 직전 점수 상위 절반(올림, 동점 포함) 중 목표 점수의 25% 이상인 참가자를 데뷔조로 선발합니다. 선발 자격은 유지합니다. 동점은 같은 순위·보너스를 받습니다.
- 평가 보너스는 1위 +40P, 2위 +25P, 그 외 +15P입니다. **데뷔조 선발 + 목표 점수 달성**을 만족하면 게임이 끝나고 데뷔 화면이 나옵니다.
- 경험치 60마다 레벨이 오르며 3D 말의 크기가 성장합니다. 각 능력치는 100이 최대입니다.

## 그래픽과 자료

24칸 보드, 기획사 미니어처, 데뷔 무대, 조명·그림자, 움직이는 말은 실제 Three.js WebGL 장면입니다. 드래그·스크롤·시점 버튼으로 회전 및 확대할 수 있습니다. WebGL 생성 실패 시 간편 2D 보드에서도 게임을 진행할 수 있습니다.

카리나·장원영·제니·나연의 공개 행사 사진을 캐릭터 선택/프로필과 입체 말의 원형 초상 텍스처에 사용합니다. 3D 말은 절차적으로 만든 미니어처이며 실제 인물을 스캔한 실사 3D 모델은 아닙니다. 사진 원본은 `public/idols/`에 저장했습니다. [사진별 출처·라이선스](public/idols/CREDITS.md)는 게임의 **사진 출처**에서도 열 수 있습니다. 인물이나 기획사의 공식 제작·후원을 의미하지 않으며 능력치·훈련 배치는 가상 설정입니다.

음향 버튼을 켜면 Web Audio로 합성한 조작 효과음이 재생됩니다. 실제 가수의 음원이나 음성 인식·보컬 분석은 사용하지 않습니다.

## 저장

이 브라우저의 `localStorage` 키 `debut-on.game.v1`에 턴, 이동 진행, 능력치, 점수, 월말 결과를 저장합니다. 새로고침 후 이어서 진행하며 미니게임 조작 중 새로고침하면 해당 미니게임의 시작 화면에서 재개합니다. 진행 중인 배틀의 완료된 첫 번째 퍼포먼스는 보존됩니다. 새 게임은 기존 게임을 교체합니다.

## 검증

```sh
npm run test:game
npm run test:game:e2e
npm run build
```

E2E는 Chrome과 실행 중인 개발 서버를 사용합니다. 기본 URL은 `http://localhost:5175`이며 `GAME_TEST_URL`로 변경할 수 있습니다. 규칙 테스트는 1~4인 완주, 동점, 순차 배틀, 능력치 제한, 저장 검증과 데뷔 조건을 다룹니다. 브라우저 테스트는 WebGL과 이미지, 사람 간 배틀, 미니게임 타임아웃, AI, 월말 평가·데뷔, 모바일 조작을 확인합니다.

주요 파일: `src/game/engine.ts` (규칙), `BoardScene.tsx` (3D), `Challenge.tsx` (미니게임), `GameApp.tsx` (게임 화면), `GameEvents.tsx` (이벤트·결과), `game.css` (반응형 스타일).
