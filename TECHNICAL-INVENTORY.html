05 / Evidence

조사 기준과 경계

“사용했다”는 판단의 근거와 포함하지 않은 항목을 명시합니다.

확인한 근거

  • 7개 package.json의 dependencies, devDependencies, scripts, engines
  • park/, dopamin/, map/, movie/, pinball/, voice/, webpage/ 소스와 설정
  • 각 README의 실행 환경·구현 범위·검증 방법
  • 실제 import 구문, 브라우저 API 호출, Swift 프레임워크 및 FFmpeg 인자
  • 테스트·리포트·골든·트레이스 파일의 존재와 실행 스크립트

분류 원칙

  • node_modules, dist, HTML coverage, 생성 리포트 내부의 중복 코드는 새 기술로 세지 않았습니다.
  • 사진·오디오·영상·폰트·도면은 포맷과 처리 기술만 포함했습니다.
  • 문서에만 언급되고 미검증인 Google Maps 키, OpenCellID 키, WebMCP 네이티브 실행은 조건부 기술로 표시했습니다.
  • 운영용 DB, 로그인, 원격 멀티플레이, 클라우드 배포 프레임워크는 현재 소스에서 확인되지 않았습니다.

주요 로컬 데이터 방식

  • BREW RACERS: IndexedDB — 프로필·음성·레이스 로그
  • DEBUT : ON / VITALIS: localStorage
  • DROP LAND / Voice CLI: 기본 상태는 메모리
  • Park / Movie / ATLAS 자동화: JSON 상태와 파일 시스템
  • 민감한 지도 API 키: Git 제외 .env.local, 일부 서버 전용
