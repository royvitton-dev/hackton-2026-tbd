# VITALIS — MAKE IT COME ALIVE

해커톤 30초 샘플 필름. 발표 화면용 16:9 · 1920×1080 · 30fps.

연출 참고: [aespa ‘Whiplash’ 공식 MV / SMTOWN](https://www.youtube.com/watch?v=jWQx2f-CErU). 이 샘플은 흑백·강한 대비, 과감한 프레이밍, 비트에 맞춘 컷, 큰 타이포그래피를 조합하는 방향으로 구성했다. 원곡이나 원본 영상은 사용하지 않았다. 음악은 120 BPM 자체 생성 전자음 비트다.

## 촬영과 편집

- 사람·책상: 24~35mm 상당 광각. 인터뷰: 50mm 상당 또는 스마트폰 2배 렌즈. 가급적 가로 4K로 찍어 후반 줌에 여유를 둔다.
- 조명: 한쪽에 강한 흰 조명, 배경은 어둡게. 화면·소품에 라임색을 작게 반복한다.
- 키보드 누르기 → 엔터 → 데모 클릭을 비트에 맞춰 연결한다. 실제 촬영본에서는 두 컷의 움직이는 방향을 맞춰 짧은 휩팬을 추가할 수 있다.
- 얼굴 인터뷰는 오래 흔들지 않는다. 질문은 잘라내고 답변 한 문장과 현장 호흡을 남긴다.
- 120 BPM이므로 한 박자는 0.5초다. 음식·손·표정은 1~2박, 주요 데모는 4박 이상 유지한다.
- 원본 음식 소리·엔터 소리·짧은 웃음을 별도 수집하면 리듬에 얹기 좋다. 인터뷰 중에는 음악을 약 11dB 낮춘다.

## 샘플의 사실 관계

- 앱과 소스: `../webpage`의 VITALIS 건강 앱. 촬영 시 `/health/` 경로 사용. 화면은 실제 브라우저 조작 결과다.
- 인물·개발 현장·음식: 내장 imagegen으로 만든 가상 재연 스틸에 줌을 적용했다. 실제 현장 동영상이 아니다.
- 인터뷰: 가상 인물, 예시 대사, macOS Yuna 합성 음성. 실제 참여자 발언이 아니다.
- T+00/02/06/10은 예시 일정이며 실제 개발 시간을 추정한 것이 아니다.
- 실제 제출본에서는 일정, 팀원 인터뷰, 개발 현장, 먹거리·웃음 부분을 행사 원본으로 바꾼다. 장면별 표시를 확인한 후 해당 재연 표시도 함께 수정한다.
