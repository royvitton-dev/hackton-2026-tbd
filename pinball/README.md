# DROP LAND · 행운이 굴러오는 3D 놀이공원

친구들의 이름·번호·선택지가 붙은 공으로 당첨자와 순서를 정하는 무료 웹 게임입니다. **독자적인 긴 코스 5종, 네온 놀이기구가 있는 실제 3D 화면, 맵마다 골인 구멍 1개와 일부 맵의 중간 리턴 포털**을 제공합니다. 공의 충돌, 실제 도착 순서와 마지막 남은 공이 결과를 결정하며, 당첨자를 먼저 뽑고 경기를 꾸미는 코드가 없습니다. 결제·코인·환전·계정·실물 보상·광고·외부 API는 없습니다.

## 실행

Node.js 20 이상이면 패키지 설치 없이 실행됩니다. Three.js 0.183.0은 MIT 라이선스와 함께 `vendor/`에 포함되어 있어 런타임 CDN 연결이 없습니다.

```sh
cd /path/to/pinball
node scripts/serve.mjs
# 브라우저: http://127.0.0.1:4188
```

현재 작업 결과물에서 바로 실행하려면:

```sh
cd /Users/gschargev/Documents/Codex/2026-09-21/new-chat-4/outputs/pinball-rush
node scripts/serve.mjs
```

- 서버는 `127.0.0.1`에만 바인딩합니다. 종료는 `Ctrl+C`입니다.
- 포트가 사용 중이면 `PORT=4189 node scripts/serve.mjs`로 변경합니다.
- ES modules와 WebGL을 사용하므로 HTML 파일을 `file://`로 직접 열지 마세요.
- `npm start`, `npm test`, `npm run build`도 사용할 수 있습니다. `npm install`은 필요하지 않습니다.

```sh
node --test tests/physics.test.mjs tests/motion.test.mjs tests/finish-rules.test.mjs tests/devices.test.mjs tests/course-devices.test.mjs tests/return-portals.test.mjs tests/parade.test.mjs tests/lotto.test.mjs
node scripts/build.mjs
node scripts/serve.mjs --dist
```

## Mac·Android 실행 파일

macOS용 앱과 Android용 오프라인 APK를 추가했습니다. Mac 앱은 Node 설치 없이 더블클릭하면 기본 브라우저에서 게임을 엽니다. Android APK는 게임 파일을 내장하며 인터넷 권한이 없습니다.

소스·재빌드 방법은 [실행 파일 안내](desktop/README.md), 검사 결과는 [패키지 검증 기록](evidence/park-20260921/25-packaging.md)을 확인하세요. Mac은 Apple Silicon/macOS 13.5 이상용이며 초기 런처의 실제 실행을 확인했습니다. 최신 패키지의 재실행 여부는 패키지별 검증 기록을 따릅니다. Android는 Android 8.0 이상 대상으로 빌드·서명·자산 검사했으며 **실제 Android 기기 설치는 미검증**입니다.

## 조작과 참가자

1. 기본 참가자는 **병우, 종호, 동길, 태성, 순수**입니다. 페이지를 열거나 새로고침할 때 이 다섯 이름의 순서를 무작위로 섞습니다. **플레이어** 탭에서 자유롭게 수정할 수 있으며, `병우, 종호*3, 동길`처럼 콤마로 이름·번호·미션을 구분합니다. 입력 후에는 탭·맵·규칙 변경이나 다시 플레이로 이름 순서를 다시 섞지 않습니다. 빈 항목과 앞뒤 공백은 무시합니다. 줄바꿈 자체는 새 참가자를 만들지 않고 이름 안의 공백으로 처리합니다.
2. 기본 공 수는 1개입니다. `지우*3`이면 지우의 공 3개입니다. `하늘, 지우*3, 민준`은 참가자 3명·총 5개 공입니다. **참가자별 공 개수**를 펼쳐 수정할 수도 있습니다.
3. 첫 번째 도착·마지막으로 남기·지정 순위 도착 중 규칙을 선택합니다. 맵 5종 중 하나를 고릅니다.
4. **공 섞고 시작하기**를 누르면 1.8초 섞기 → 3초 카운트다운 → 출발 게이트 개방 순으로 진행됩니다.
5. 첫 번째·지정 순위는 그 순위의 공이 결승 구멍에 들어간 순간 바로 멈추고 당첨자를 크게 표시합니다. 마지막 규칙은 공이 하나만 남는 순간 바로 멈추며, 그 공이 당첨됩니다. 마지막 공을 허위 도착으로 기록하지 않습니다.
6. **다시 플레이**는 같은 설정에 새 난수를 사용합니다. 설정 변경 버튼으로 대기 상태로 돌아가 참가자·규칙·맵을 변경합니다.

| 항목 | 지원 범위 |
| --- | --- |
| 참가자 | 1~60명 |
| 참가자별 공 | 1~10개 |
| 전체 공 | **1~60개** |
| 이름 길이 | 유니코드 코드 포인트 1~40자 |
| 전체 입력 | 6,000 UTF-16 코드 유닛 이하 |
| 지정 순위 | 1~전체 공 수의 정수 |

동일한 이름은 별도 참가자로 유지합니다. 두 번째부터 `(2)`, `(3)`을 붙입니다. 이름을 자동 합치거나 공 수를 조용히 잘라내지 않습니다. 콤마는 참가자 구분자, `*`는 공 개수 구분자이므로 이름 자체에 사용할 수 없습니다. CSV 따옴표로 구분자를 이스케이프하는 형식은 지원하지 않습니다. 여러 공을 가진 참가자는 도착 목록에 여러 번 등장할 수 있습니다. 긴 이름은 공 위에서만 축약하며, 참가자 목록과 결과에는 전체 이름이 표시됩니다.

- **일시정지·재개:** 공 위치, 순위, 장애물 위치와 경기 시간을 그대로 보존합니다. 섞기·카운트다운 중에도 동작합니다. 작은 안내창 아래로 멈춘 경기장과 공을 계속 볼 수 있습니다. 입력창·버튼에 포커스가 없을 때 Space 키로도 정지·재개합니다.
- **결과 화면 키보드:** 당첨되면 결과 제목으로 초점이 이동합니다. Tab으로 다시 플레이·순위 보기를 선택하고 Enter로 실행합니다. Escape로 결과를 닫으면 확정 결과 카드로 이동합니다. 결과에서 다시 플레이하면 일시정지 버튼에 초점이 이어집니다.
- **처음부터:** 현재 경기를 폐기하고 같은 설정의 대기 상태로 돌아갑니다. 이전 당첨·순위는 지워집니다.
- **크게 보기:** 경기장을 화면 중심으로 확대하고 출발·정지·배속 버튼을 가까이 둡니다. 원래 화면 버튼 또는 Escape로 돌아갑니다. 배치·시점 변경은 경기 상태에 영향을 주지 않습니다.
- **전체 맵 / 하프 모드 / 따라가기:** 전체 맵과 하프 모드는 경기장을 창 전체로 확장하고 비율을 유지합니다. 하프 모드는 코스 길이의 절반을 확대해 진행 구간을 따라갑니다. 같은 버튼을 다시 누르면 가까이 따라가기로 돌아갑니다. 원래 화면 버튼 또는 Escape로 일반 UI에 복귀합니다. 카메라는 판정에 관여하지 않습니다.
- **상단 / 입체 / 측면 시점:** 기본은 위에서 보는 고정 각도로 진행 구간을 따라갑니다. 경기장 우측 상단에서 3D 카메라 각도를 바꿉니다. 원근 카메라와 실제 입체 메시를 사용하며, 두꺼운 보드 측면·받침·그림자를 볼 수 있습니다. 정지 중 시점을 바꿔도 공과 순위는 움직이지 않습니다.
- **이름 간결하게 / 이름 모두 보기:** 기본은 겹치는 이름표를 줄여 공의 경로를 잘 보이게 합니다. 필요하면 모든 이름을 표시할 수 있습니다. 전체 이름과 도착 순위는 결과 목록에서 확인합니다.
- **1× / 1.5× / 2× / 3×:** 기본은 **1.5×**입니다. 대기 중·경기 중·일시정지 중 바꿀 수 있습니다. 더 많은 고정 물리 스텝을 실행해 재생만 가속하며, 순위·구멍 판정·경기 시간은 같은 물리 기준을 사용합니다.
- **스윙 보드:** 시작 전에 켜거나 끕니다. 경기 시작부터 3~5초 사이의 시드 기반 무작위 간격으로 1.8초 동안 좌우로 최대 약 4.5도 기울고 보드 중심이 약 21물리단위 이동하며, 모든 공에 같은 방향과 세기의 실제 가속도를 줍니다. 이전 버전보다 힘과 기울기를 3배 높였습니다. 경기 도중 설정은 잠깁니다. 시드와 시간만 사용하며 이름·순위·당첨 규칙은 참조하지 않습니다.
- **자석과 대포:** 모든 맵에 자석 2개가 있고, 기존 4개 맵은 대포 2개, 캐논 퍼레이드는 대포 9개입니다. 자석은 가까운 공을 당겨 실제 접촉 위치에서 0.5~1초 붙잡고 놓습니다. 대포는 V자 깔때기 안에 들어온 공을 붙잡고 **0.4초마다 한 바퀴** 회전합니다. 기존 맵은 0.5~1초, 캐논 퍼레이드는 **0.8~1.5초** 후 그 순간의 실제 포신 방향으로 초당 740 단위로 발사합니다. 대포별 회전 방향·시작 위상은 시드로 정하며 위쪽 발사도 가능합니다. 대기 시간은 120Hz 시뮬레이션 기준이며 재생 속도에 따라 화면상의 시간도 빨라집니다. 여러 공을 동시에 포획하며 각 공은 해당 장치 범위 안에서 독립적인 무작위 대기 시간을 갖습니다. 자석은 공을 보드 위로 들어 올리고 대포는 내부에 저장하므로 대기 공이 입구를 막지 않습니다. 공별 타이머가 끝날 때 자석은 방출하고, 대포는 그 순간 실제 포신 방향으로 발사합니다. 잡혀 있는 공의 수를 장치 위에 표시합니다. 방출한 공은 2초 동안 재포획하지 않습니다. 이름·규칙·순위를 참조하지 않으며 시드가 같으면 대기 시간과 발사 방향도 재현됩니다.
- **골인과 리턴:** 캔디 행성·원더 가든의 마지막 분홍 `BACK` 구멍은 도착 순위에 집계하지 않습니다. 공이 구멍으로 내려간 뒤 중간 구간 (캔디 행성 `(310, 1200)`, 원더 가든 `(170, 1120)`) 위에서 다시 떨어져 경기를 이어갑니다. 연출과 이동은 물리 시간에 묶이며 정지 중에도 함께 멈춥니다. 모든 공은 같은 리턴 위치와 속도 범위를 사용하고, 재진입 횟수는 화면에 표시합니다. 노란 `GOAL` 구멍을 실제로 통과해야 도착입니다. 반복 리턴으로 경기가 길어지는 것을 막기 위해 경기 60초에 모든 공에 동일하게 피날레 유도 레일이 나타나 리턴 쪽으로 새로 진입하는 통로를 막고 골인 방향으로 안내합니다. 이미 리턴 통로 안에 있던 공은 열린 리턴 구멍으로 빠져나온 뒤 중간에서 다시 시작합니다. 통로 안에 가두는 덮개는 사용하지 않습니다. 리턴을 골인으로 바꾸어 집계하지 않습니다. 이 전환은 이름·순위와 무관한 고정 경기 시간 규칙입니다. 마지막 규칙에서 리턴 중인 공만 남아도 그 공이 마지막 남은 공으로 당첨됩니다.
- **네온 구간:** 각 코스의 세 구간에 네온 레일·별 조명·바닥 광륜이 있습니다. 빛은 천천히 변하고 연출 줄이기를 켜면 일정하게 유지됩니다. 판정에는 관여하지 않습니다.
- **큰 당첨자 안내:** 규칙을 달성하는 즉시 경기장 중앙에 이름과 당첨 이유를 크게 표시합니다. 첫 번째·지정 순위는 실제 도착 순위를, 마지막 규칙은 마지막 남은 공임을 표시합니다. 한 번 더 타기·전체 순위 보기 버튼을 제공합니다.
- **소리:** 기본 음소거이며 상단 소리 버튼으로 켭니다. 반짝이는 벨, 통통 튀는 타악음, 대포 발사·자석 포획, 출발 멜로디와 약1.7초의 당첨 팡파르 등13종을 Web Audio로 합성합니다. 직접 구성한 놀이동산풍 소리로 외부 음악 파일·네트워크가 필요 없습니다. 동시 음원40개 제한과 충돌음 간격 제한을 적용하며, 음소거·일시정지·재시작·탭 이탈 시 예약된 소리와 잔향도 취소합니다. 소리 변주는 경기 난수나 순위에 영향을 주지 않습니다.
- **연출 줄이기:** OS 설정을 처음 반영합니다. 축하 조각·슬로모션·잔상·충돌 파동·보드의 시각적 기울임을 끄며 카메라 보간을 줄입니다. 경기 물리는 동일합니다.
- 브라우저 탭을 떠나면 자동 일시정지합니다. 돌아온 후 재개를 누르세요. 그래픽 연결이 끊기면 안내를 표시하고 시작·재개를 막습니다. 연결이 돌아오면 **화면 복구하기**를 누르세요. 복구 후에도 공 위치·도착 순위·보던 구간을 유지하며, **재개**를 눌러야 진행합니다. 그리기 오류도 같은 복구 흐름을 사용합니다. 연결이 끝내 돌아오지 않아 페이지를 새로고침하면 현재 경기는 복원되지 않습니다.
- 모바일에서는 설정 → 경기장 → 결과 순으로 배치되며, 시작할 때 경기장으로 이동합니다. 버튼은 터치와 키보드로 조작할 수 있습니다. 결과 안내는 라이브 영역으로 제공합니다.

## 로또 탭

1~45번이 각각 같은 사양의 공 하나로 참가합니다. 참가자 이름이나 공 수 입력은 사용하지 않습니다. 플레이어 탭으로 돌아오면 입력했던 이름·수량을 유지합니다. 경기 중에는 탭과 규칙을 바꿀 수 없습니다.

- **처음 6개 + 보너스:** 실제 1~6등이 당첨 숫자, 7등이 보너스입니다. 7번째 통과 순간 종료합니다.
- **마지막 6개 + 보너스:** 실제 39~44등이 당첨 숫자, 마지막으로 남은 미도착 공이 보너스입니다. 44번째 통과 순간 종료하며 보너스 공을 도착한 것처럼 집계하지 않습니다.
- 당첨 숫자 6개는 결과 카드에서 작은 숫자부터 정렬하고 보너스는 별도로 표시합니다. 도착 순위 목록은 실제 순서를 유지합니다. `exportRound().lotto`에 숫자·보너스·실제 도착 여부를 보존합니다. 미도착 보너스의 `bonusRank`는 `null`이며 허위 45등 기록을 만들지 않습니다.
- 다시 플레이는 새 시드로 45개 공을 다시 섞습니다. 모든 결과는 실제 경기 기록에서 계산합니다. 이 기능은 게임의 숫자 선택 모드이며 외부 복권 구매·결제·실제 추첨 결과 연결이 없습니다.

## 물리와 판정

- 질량·반지름·반발 계수는 모든 공에 동일합니다. 반지름은 10 물리 단위입니다.
- 물리는 1/120초 고정 간격의 평면 시뮬레이션입니다. 중력, 공끼리의 충돌, 원형 핀·범퍼, 선분 레일·회전문·이동 장애물을 계산합니다. 일반 속도는 초당 560 단위, 대포 발사 직후 0.55초는 최대 780 단위로 제한하고 각 스텝에서 4회 충돌 보정을 수행합니다.
- 실제 3D 화면은 Three.js WebGL의 PerspectiveCamera와 입체 메시로 그립니다. 두께 0.8의 보드·뚫린 구멍·금속 핀·받침·조명·그림자·공의 반사광을 제공합니다. 공의 이동·충돌 계산은 보드 평면에서 이루어지며 자유 낙하하는 3축 강체 물리는 아닙니다. WebGL 초기화가 불가능한 기기에만 Canvas 2.5D 호환 화면을 제공합니다.
- 회전 막대는 맵 안에서 서로 다른 속도와 방향으로 움직입니다. 네 날개 풍차는 수직으로 교차하는 두 개의 실제 충돌 막대를 사용하고, 바이킹은 정현파 각도와 그 미분인 실제 각속도로 왕복합니다. 회전목마·우주선·범퍼카는 둥근 바닥 테두리가 실제 원형 충돌 범위입니다. 회전목마 범퍼의 반발 계수는 1.12로 작은 에너지를 더하며 공의 속도 제한은 유지합니다. 충돌 효과는 실제 접촉 이벤트에서만 발생합니다.
- 출발 위치와 순서는 `crypto.getRandomValues`에서 받은 시드와 Fisher–Yates 섞기로 결정합니다. 경기 중 무작위는 탈출 보조, 장치별 회전·공별 대기 시간, 리턴 방출 속도에도 사용합니다. 이름·규칙·순위로 당첨자를 선택하지 않습니다.
- 별빛 축제·구름 코스터·캐논 퍼레이드는 x=310의 골인 하나, 캔디 행성·원더 가든은 x=240의 골인과 x=380의 리턴 구멍을 둡니다. 모두 폭 80입니다. 중앙 입구와 양쪽 합류 경사 레일은 실제 충돌 대상입니다.
- 공 중심이 y=2,150 판정선을 **구멍 안쪽으로** 넘어가야 도착합니다. 같은 물리 스텝 안에서도 선형 보간한 통과 시각으로 순서를 매깁니다. 구멍 사이로 선을 넘는 비정상 경로는 집계하지 않고 되튕깁니다.
- 완전히 동일한 통과 시각은 시작 때 정한 무작위 우선값, 그 값까지 같으면 고유 공 ID로 판정합니다. 특정 이름이나 입력 순서에 유리한 당첨자 선정 기능은 없습니다.
- 각 공은 고유 ID와 `finished` 상태를 가지며 한 번만 집계됩니다. 첫 번째/N번째의 당첨자는 선택한 순위의 실제 도착 기록입니다. 마지막 규칙은 실제 도착이 N-1개가 된 시점의 미도착 공 하나를 당첨자로 선택하며 도착 목록에 추가하지 않습니다. 당첨 규칙은 종료 시점만 바꾸고 그 이전의 물리 경로·도착 기록을 바꾸지 않습니다.
- 종료 시점은 도착 판정에 사용한 세부 통과 시각으로 맞춥니다. 완전히 같은 시각에 통과한 공들도 시드 우선값으로 순서를 정하며 목표가 달성된 이후의 순위는 추가 집계하지 않습니다. 공 한 개로 마지막 규칙을 선택하면 출발 게이트가 열린 순간 그 공의 당첨을 확정합니다.
- `exportRound()`의 마지막 규칙 당첨자는 `criterion: last-remaining`, `crossedFinish: false`, `exitId: null`입니다. `rank`는 마지막 순서에 해당하는 전체 공 수를 나타내고 실제 도착 목록에는 포함되지 않습니다. 제품은 `finishMode: winner`로 실행하며, 물리 QA용 전체 코스 모드(`all`)는 마지막 공까지 추적해 지형의 정체·완주를 검사합니다.
- 슬로모션은 물리 스텝을 처리하는 화면 시간만 늦춥니다. 스텝 크기·난수·순위 판정은 바뀌지 않습니다. 같은 Chrome에서 연출·일시정지 없이 재실행한 결과가 화면 경기와 일치하는지 검증합니다.

## 정체·실패·무작위성의 한계

- 공이 기준 위치에서 20단위 이내에 4.5초 이상 머물거나, 8.5초 동안 아래로 24단위 이상 진행하지 못하면 좌우 무작위 방향의 동일한 크기 탈출 충격을 줍니다. 순간이동하거나 임의 순위를 부여하지 않습니다. 화면에 보조 횟수를 표시합니다.
- 당첨 조건을 달성하기 전에 경기 물리 시간 90초(캐논 퍼레이드 120초, 리턴이 있는 맵은 150초)가 되거나 좌표에 비정상 값이 생기면 **무효 경기**입니다. 임의의 공을 당첨시키지 않으며 다시 플레이할 수 있습니다.
- 균등한 출발 섞기와 동일한 공 사양은 **당첨 확률이 완전히 같다는 증명은 아닙니다.** 지형·충돌 순서·수치 오차·공 개수·탈출 보조가 결과에 영향을 줍니다. 확률 검정이나 인증은 수행하지 않았습니다.
- 시드가 같아도 **다른 JS 런타임/브라우저/버전의 결과는 같다고 보장하지 않습니다.** Node와 Chrome 간 약 7.1e-15의 초기 수치 차이가 충돌 과정에서 커져 순서가 갈라지는 사례를 실제 확인했습니다. 제공한 시드는 같은 환경에서의 재현·디버깅용입니다.
- 연속 충돌 탐색이나 강체 전문 엔진을 사용하는 것은 아닙니다. 작은 스텝, 속도 제한, 반복 충돌 보정으로 검증 범위에서 관통·이탈을 방지합니다. 무한한 모든 입력·기기·실행 시간을 검증한 것은 아닙니다.
- 카메라 밖 공은 오른쪽 진행 막대로 표시됩니다. 많은 공이 겹친 구간에서는 이름표도 겹칠 수 있습니다. 참가자별 목록 및 전체 도착 순위가 전체 이름의 기준입니다.
- 설정과 경기 기록은 페이지 메모리에만 있습니다. 새로고침하거나 탭을 닫으면 초기화됩니다. 조작 방지 서버나 외부 결과 인증은 없으므로 실제 자산·상금용 시스템이 아닙니다.

경기 시작 시 보드가 창을 채우며, 출발·정지·초기화는 경기장 하단의 별도 영역에서 조작합니다. `원래 화면`으로 참가자 설정과 결과 영역을 다시 볼 수 있습니다. 하프·전체 맵은 가로로 넓은 창에서 코스를 가로 방향으로 배치하고, 세로 창에서는 세로 방향을 유지합니다. 공과 물리 보드의 비율을 유지하는 카메라 조정으로, 공 크기·충돌 판정 자체는 바뀌지 않습니다. 기본 따라가기 시점은 진행 구간을 더 가까이 보여 줍니다. 전체 맵은 긴 코스를 모두 보여주므로 공을 자세히 볼 때는 따라가기/하프 모드를 사용합니다. 창 크기를 바꾸거나 휴대전화 방향을 돌려도 경기 상태는 유지됩니다.
