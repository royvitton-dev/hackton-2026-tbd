# PINBALL CLUB

무료 물리 기반 핀볼 복불복 웹 게임. 네온 드롭, 오비트 클럽, 스위치백, 포크 앤 플로우의 4개 맵. 공을 미리 당첨시키지 않고 실제 결승선 통과 기록으로 첫째·마지막·N번째 당첨자를 정합니다.

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node scripts/serve.mjs
# http://127.0.0.1:4188
node --test tests/physics.test.mjs
node scripts/build.mjs
```

참가자는 한 줄에 하나씩 입력합니다. 기본 공 개수는 1개이며 `하늘 | 3` 또는 참가자별 입력란으로 변경할 수 있습니다. 합계 1~60개, 참가자별 1~10개, 이름 40자까지 지원합니다. 같은 이름도 별도 참가자이며 두 번째부터 (2), (3)으로 구분합니다.

경기 중에는 설정이 잠깁니다. 일시정지·재개는 같은 경기를 이어가고, 처음부터는 진행 중 결과를 버리고 대기 상태로 돌아갑니다. 다시 플레이는 같은 설정에 새 난수로 출발합니다.

모든 공의 크기와 질량은 같습니다. 120Hz 고정 간격 충돌 시뮬레이션이며 화면은 Canvas 2D 투영으로 만든 2.5D입니다. 동시 도착은 세부 통과 시각, 완전히 같으면 출발 시 섞은 우선값으로 정합니다. 4.5초 정체에는 동일한 탈출 충격 규칙을 적용하며, 90초 미완주 또는 비정상 물리 상태는 무효 경기로 처리합니다. 공별 당첨 확률이 완전히 같다는 보장은 없습니다.

개발 검증 중간 기록입니다. 최종 브라우저 검증·성능·시연·세션 기록은 evidence/에 추가됩니다. 기존 프로젝트 파일을 수정하지 않는 독립 폴더입니다. 결제·코인·로그인·외부 통신이 없습니다.
