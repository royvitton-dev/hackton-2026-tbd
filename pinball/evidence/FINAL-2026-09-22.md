# DROP LAND 최종 전달 기록 — 2026-09-22 09시 작업 마감

게임과 Mac 실행 앱, Android APK를 제작했다. 웹 게임 검증은 아래 범위에서 통과했으며, 원더 가든 정체와 Android 자체 실행은 남은 항목이다. 따라서 모든 완료 기준을 충족했다고 표시하지 않는다.

## 완성한 기능

- 실제 3D 메시·조명·그림자, 긴 코스 5종: 별빛 축제, 캔디 행성, 구름 코스터, 원더 가든, 캐논 퍼레이드.
- 수정 가능한 기본 5명과 페이지 진입마다 무작위 순서, 콤마 입력과 `이름*개수`, 샘플 20명. 참가자당1~10개, 전체 최대60개.
- 첫 번째·지정 순위 실제 도착 즉시 종료, 마지막 남은 공 당첨. 로또1~45의 처음6+7번째보너스 / 마지막6+남은공보너스.
- 기본1.5배속·1/2/3배속, 정지·재개·재경기, 음소거, 연출 줄이기, 시점 전환·전체창·하프모드.
- 놀이기구 장애물·네온·3~5초 무작위 보드 스윙. 자석·대포의 다중 포획과 독립 방출, 캐논 퍼레이드9대포, 대포0.4초 회전.
- 맵마다 GOAL1개, 캔디·원더의 BACK 중간 리턴. 대형 당첨 안내, 결과 키보드 조작, 그래픽 연결 손실 중 진행 차단과 상태 보존 복구.

## 남은 실패와 미실행

- 원더 가든은 드물게 출구에서 정체한다. 최신 장기 검사에서40개 중39개 도착 후150초 무효 사례가 있다. 구조 수정3회 실패 후 추가 시도를 중단했고 구조 선택 답변을 기다린다. 무효 경기에 당첨자를 꾸며 넣지 않는다.
- Android APK는 빌드·서명·웹 자산만 검증했다. 실제 Android 기기·에뮬레이터 설치, WebView 생명주기·뒤로가기·회전은 미실행이다. SDK 약관 및 설치 동의는 아직 받지 않았다.
- Mac 최초 런처는 실제 실행했으나 최신 패키지의 네이티브 창 재실행은 미실행이다. 최신 게임 웹 빌드와 패키지 파일 일치만 확인했다. 앱은 로컬 서명이며 공증되지 않았다.
- 실제 iOS, Safari/Firefox, 스피커 청취, 전체 접근성 감사, 당첨 확률의 통계적 동등성은 미검증이다. 공의 사양은 같지만 모든 참가자의 당첨 확률이 완전히 같다고 주장하지 않는다.

## 실제 작업 시간과 Git 전달

기능 수정·검증은9월21일23:30경까지 수행했다. Mac 잠금과 남은 사용자 입력 때문에23:32에 목표를 대기 상태로 전환했다. 이후 동일한 접근 실패를3회 확인한 뒤 재시도를 멈췄으며 밤새 게임 검사를 계속했다고 주장하지 않는다.9월22일08:19과09:01에는 원격 포함 여부만 확인했다.

09시 이후 사용자의 명시적인 `git pull, push` 요청으로 전달을 재개했다. main의 pull은 이미 최신이었다. CLI push는 HTTPS 사용자명 인증 부재로 실패했고, 잠금이 해제된 Fork의 기존 인증으로 일반 Push를 실행했다. Fork는 Everything is up-to-date를 표시했으며09:04 실제 원격과 로컬이 `4633dc89f672581f648c1290ab35e3958f58e815`로 일치하고 대기 커밋4개가 모두 포함됨을 확인했다. 강제 푸시·토큰 추출은 하지 않았다. 푸시 시점에 사용자의 병행 작업이 있었으므로 원격 확인 사실을 기준으로 기록한다.

4188은 `main-4633dc89f672`로 갱신했고 별도 Chrome의 첫 열기·새로고침에서21파일 일치를 확인했다. 열린 사용자 경기를 강제로 새로고침하지 않았다. 이 문서를 포함한 마지막 문서 커밋의 전달 결과는 후속 전달 영수증으로 보존한다.

## 실행과 증빙

Node.js20 이상에서 패키지 설치 없이 게임 폴더에서 실행한다.

```sh
node scripts/serve.mjs
# http://127.0.0.1:4188
```

Mac은 `DROP-LAND-macOS-arm64.zip`을 풀고 `DROP LAND.app`을 실행한다. Android 파일은 `DROP-LAND-Android.apk`다. 실행 대상·설치 안내와 한계는 각 패키지 안내문을 따른다.
