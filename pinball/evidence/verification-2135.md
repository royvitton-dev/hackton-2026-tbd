## 실패·보류

- **원더 가든 출구 정체는 미해결이다.** 18 Chrome 최대60개 경기에서58개 도착 후150초 제한에 걸렸다. 원래 출구 회전판, 중앙으로 이동한 회전판(20), 리턴 차단 레일을 낮춘 배치(20b) 모두 일부 조건에서 정체가 발생했다. 사용자 요청의 동일문제3회 중단 규칙에 따라 추가 재설계를 멈추고 출구 구조 선택을 요청했다. 실패한 시험 배치는 배포하지 않고 기존 배치를 유지한다. 위600개 Node 표본의 통과가 Chrome의 희귀 정체 해결을 의미하지 않는다. 미완주는 무효 처리하며 결과를 임의로 만들지 않는다.
- [20 실패](park-20260921/20-garden-soak-results.json): 중앙 회전판과60초 차단 레일의 겹침. [20b 실패](park-20260921/20b-garden-soak-results.json): 차단 레일 아래·구멍 사이 분기점에1개 잔류. 실패 당시 코드와 JSON을 보존했다. 20b PC/모바일 리턴4/4 통과만으로 이 후보를 통과 처리하지 않았다.
- 19종합40/41: 예전 특정시드가 반드시 탈출 보조를 사용한다는 테스트 가정이 깨짐. 공은 보조 없이 정상 도착했다. 실제 현행 맵의 자연 정체 시드로 갱신하고, 보조 순간 이동량·미도착·실제GOAL 완료를 검사했다. 제품을 테스트에 맞춰 변경하지 않았다.
- 초기 캐논맵16/16b는 출구 회전판이 공을 가뒀다. 겹치는 하단 회전판을 제거한 뒤16c120경기 통과. 이후0.4초 회전은 위600경기에 포함한다.
- 17브라우저는 로또 추가 후 `input[value=last]`가 두 개여서 실패했다. `name=rule`을 명시한 실제 플레이어 조작으로 수정했다. 실패 로그는 삭제하지 않았다.
- 15a 하프모드 테스트는 다른 경기의roundId까지 비교하거나 숨겨진 상단 버튼을 눌러 실패했다. 고유ID를 제외한 실제 상태 비교와 Escape로 복귀하는 조작으로 수정해15검사5/5 통과했다.

## 미실행·한계

실제 iOS/Android 기기, Safari/Firefox, 사람의 스피커 청취, 전체 WCAG 감사, 실제 브라우저200%확대, 통계적 당첨확률 동등성, 네이티브 WebMCP, 외부 호스팅은 미실행이다. 모든시드의 완주·관통 없음·공평한 당첨확률을 보장하지 않는다. 물리는120Hz 보드 평면 계산, 그래픽은 실제3D 메시·조명·카메라다.

지원은 총60개, 참가자마다1~10개. 공의질량·크기는 동일하다. 대포와 자석의 잡기·대기·방출 및 BACK 리턴은 명시적 상태로 처리한다. 리턴 진입 차단은60초에 모든공에 동일 적용한다. 일반맵90초, 캐논퍼레이드120초, 리턴맵150초 미완주는 무효다. Node와 Chrome의 부동소수점 차이로 동일 시드 경로가 달라질 수 있어 정확한 재현은 같은 실행환경 기준으로 검사한다.
