# DROP LAND 놀이공원 개선 세션

기간: 2026-09-21 한국시간 18:50부터 21:00까지. 사용자가 UI·놀이공원 분위기·지속적인 개선과 검증, main 직접 중간 커밋·푸시를 요청했다. 이후 놀이기구 모양 장애물, 약한 보드 흔들림, 기본 상단 시점 및 다른 시점 선택을 추가로 요청했다. 상단 각도를 유지하며 진행 구간을 따라가는 방식을 사용자가 확인했다.

이 문서는 실제 수행 작업과 관찰 결과의 요약이다. 미실행 항목은 완료로 표시하지 않는다.

## 01 — 19:02, 입장권 UI

- DROP LAND 이름, 크림색 티켓 바탕, 보라색·분홍색·금색 포인트, 행운 패스 그래픽, 탑승권 입력 패널, 네 테마 선택과 결과 카드 구현.
- 네 테마 이름은 별빛 축제·캔디 행성·구름 코스터·원더 가든. 물리 맵 ID 및 충돌 지형은 보존했다.
- 상단 시점을 기본으로 하고 입체·측면 변경을 유지했다.
- 구문 및 정적 빌드 14개 파일 통과. 실제 Chrome 테스트 6/6 통과: 입력 오류·공 수·순위·반복 클릭·잠금·정지·재시작·모바일·전 맵 60개 공·동일 브라우저 재현·반응형·음소거·숨김 탭.
- 60개 공 1배속 측정은 PC 맵별 평균 35.5~54.1 FPS, 모바일 에뮬레이션 48.8 FPS. 독립 전용 장비가 아니며 이후 놀이기구 그래픽의 성능은 별도로 검증한다.
- `01-ui-browser-results.json`, `01-ui-browser.log`, PC·모바일 캡처를 보존했다.

다음 묶음: 실제 3D 놀이기구 모델, 약한 실제 물리 흔들림, 조작 가독성·성능 개선. 아직 이 단계에서 완료했다고 간주하지 않는다.

## 02 — 19:09, 3D 놀이기구

- 원형 범퍼를 작은 회전목마, 회전 막대를 찻잔 놀이기구, 이동 막대를 3칸 열차로 구성했다. 사탕 핀·성문·가랜드·풍선·관람차·구름·전구 레일을 추가했다. 코스 밖 장식에 숨은 충돌은 없다.
- 반복 핀·나무·전구는 인스턴스 렌더링으로 묶고 맵 교체 때 해당 GPU 자원을 해제했다.
- 첫 카메라 검증은 일시정지 레이어가 시점 버튼을 가려 실패. 덮개 위에 시점 버튼을 배치해 실제 클릭으로 재검증 통과. 실패 로그도 별도 보존했다.
- 상단을 기본으로 PC·모바일 60개 공 3배속, 정지 중 3가지 시점 변경, 실제 도착·순위와 같은 Chrome 재현 모두 통과. PC 48.6 FPS, 모바일 에뮬레이션 52.9 FPS. 시간대·부하가 다른 측정이므로 이전 수치와 엄밀한 성능 우열을 주장하지 않는다.
- 4개 맵 각각 실제 경기·같은 브라우저 재현 통과. 40회 맵 변경 후 같은 맵의 geometry 158, texture 9, shader program 16으로 시작/종료 동일. 일반적인 장기 메모리 누수 부재를 보장하는 시험은 아니다.
- UI 커밋 a9b7a11의 첫 push는 원격 신규 변경 때문에 non-fast-forward로 실패했다. pinball 외의 두 신규 커밋을 fetch/merge하고 a1ad801에서 원격 main 해시 일치 확인. 기존 원격 파일을 덮어쓰거나 강제 푸시하지 않았다.

## 03 — 19:20, 상단 액션과 살랑 보드

- 회전 막대마다 서로 다른 절대 속도와 양방향 회전, 보드의 약한 실제 가속도(7초부터 9초 간격, 1.8초) 적용. 기본 켜짐이며 시작 전 변경 가능. 참가자·순위·당첨자를 참조하지 않는다.
- 실제 접촉의 파동, 공의 짧은 잔상, 회전목마의 충돌 반응 추가. 연출 줄이기는 시각 효과만 끄며 물리는 유지한다.
- 원형 맵 1개 공/시드 5에서 넓게 진동하며 끝나지 않는 실제 실패 발견. 위치 정체뿐 아니라 8.5초간 아래로 진행하지 못한 경우도 탈출 충격 적용. 회귀 사례 및 일반/흔들림 각각 120회 총 240경기, 단위 테스트 17/17 통과. 순간이동이나 가짜 완주 판정 없음.
- PC·모바일 60개 공/3배속, 실제 흔들림, 설정 잠금, 정지·연출 변경·재개, 순위·승자·같은 Chrome 재현, 흔들림 끄기 통과. 테스트 초안은 snapshot의 time을 raceTime으로 잘못 참조해 시간 초과. 테스트 오류를 고친 후 통과했으며 실패 JSON 보존.
- 효과를 켠 최대 수량 표본은 PC 29.0 FPS/JS 평균 10.12ms, 모바일 에뮬레이션 28.4 FPS/11.57ms. 추가 렌더링 최적화가 필요하며 이를 다음 단계로 진행한다.
- 이전 놀이기구 커밋 5d61f72는 Fork push 후 원격 main 해시 일치 확인.

## 04 — 19:28, 상단 확대와 렌더링 최적화

- 고정 상단 카메라의 코스 배율 확대. 이름표 실제 크기를 기준으로 겹침을 피하는 간결 모드, 이름 모두 보기 전환 추가. 정지 중 전환해도 물리 스냅샷 불변 및 PC·모바일 이름표 비겹침 확인.
- 정적인 장식 메시를 재질별로 묶고, 동적인 회전·이동 놀이기구는 별도 유지. 회전목마 충돌 반응은 지붕에 적용한다.
- 실제 Chrome 60개 공/3배속/연출 켜짐: PC·모바일 에뮬레이션 각각 60.0 FPS 표본. JS 평균 4.94ms/4.73ms. 흔들림·정지·재개·연출 변경, 실제 도착과 같은 Chrome 재실행 일치 통과. 결과는 해당 환경/시드의 표본이며 모든 기기의 보장이 아니다.
- 03 커밋 97c2444 push는 원격에 다른 프로젝트의 5개 커밋이 추가돼 첫 시도 거절. pinball 변경이 없는 것을 확인 후 정상 병합. 680a1ef에서 로컬·원격 main 동일 확인. 강제 push 없음.
- 4개 맵 각 12개 공 실제 완주·재현 통과. 40회 맵 교체 후 동일 맵 geometry 63, texture 9, program 17, draw calls 41로 시작/종료 동일.
