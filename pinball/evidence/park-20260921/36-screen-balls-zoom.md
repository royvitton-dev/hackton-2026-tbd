## 변경
- 경기 중 웹 Screen Wake Lock / Android 전경 KEEP_SCREEN_ON, 일시정지·종료·화면 이탈 해제. 밝기 수치·OS 자동 밝기는 변경하지 않는다.
- 스포츠 공6종 / 동물얼굴6종 / 기본컬러 선택. 경기 난수와 독립된 외형 배정, 원래 물리·순위 코드 보존.
- 공 탭 추적 확대 / 빈 보드 탭 부분 확대 / 다시 탭·Escape 복귀. 드래그는 탭으로 취급하지 않는다.
