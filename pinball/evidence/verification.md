# 실행·검증 기록

2026-09-21, 로컬 Chrome 및 Node에서 실제 실행했다. 기록은 해당 코드 시점의 측정이며 기기 전체의 성능 보증이나 당첨 확률 검증이 아니다.

## 통과

- 물리 단위 테스트 11/11. 4맵 × 1·20·60개 × 10시드 = 120경기 모두 완주, 중복 집계 없음. 이 표본의 탈출 보조 0회. `iteration-5-unit.log`, `physics-results.json`.
- 실제 Chrome 통합 테스트 6/6. 입력 → 규칙 → 경기 → 결과 → 재경기, PC·모바일 에뮬레이션, 60개 공 모든 맵, 도착 목록·승자와 같은 Chrome 물리 재실행의 일치. `iteration-6-browser.log`, `browser-results.json`.
- 빈 입력, 중복·긴 이름, 잘못된 공 수와 순위, 참가자별 수량, 연속 시작 25회, 설정 잠금, 단계별 일시정지·재개·초기화, 숨김 탭 자동 정지, 음소거·연출 줄이기, 320·768·1024px 폭 확인.
- 1·2·3배속의 같은 시드 경기: 실제 시간 31.9125·16.0049·10.6672초, 시뮬레이션 시간 모두 27.033333초, 순서 모두 p1→p3→p2→p4, 승자 p1. 경기/정지 중 배속 변경도 결과 동일. `speed-results.json`.
- 정적 빌드 13개 파일 구문·해시 검증. 빌드 산출물을 모바일 390×844, DPR 2에서 WebGL 및 강제 WebGL 불가 환경으로 각각 실행. 3배속 N번째 당첨·네 구멍·순위·재경기·초기화 통과. 페이지 오류·HTTP 오류·가로 넘침 없음. `build-smoke.json`, `iteration-8-build-smoke.log`.

## 최대 60개 공 성능

3D 경기 초반 약 5.5초의 requestAnimationFrame 간격을 측정했다. 전용 벤치마크 환경이 아니며 다른 앱과 미리보기가 실행 중이었다. JS 비용은 GPU 전체 시간이 아니다. 모바일은 실제 휴대폰이 아닌 Chrome 에뮬레이션이다. 아래 첫 표는 원근 카메라 적용 전 1배속 측정이다.

| 환경 / 맵 | 평균 FPS | JS 평균 ms | JS p95 ms | 프레임 간격 p95 ms |
|---|---:|---:|---:|---:|
| PC 1440×1000 / 네온 | 43.2 | 2.79 | 4.0 | 33.4 |
| PC / 원형 | 57.9 | 1.79 | 2.5 | 16.8 |
| PC / 지그재그 | 56.3 | 1.65 | 2.4 | 33.3 |
| PC / 갈림길 | 58.4 | 1.84 | 2.3 | 16.8 |
| 모바일 390×844 DPR 2 / 네온 | 56.2 | 2.55 | 3.7 | 33.3 |

최종 원근 3D 카메라에서 **60개 공·3배속**을 추가 측정했다. 네온 맵의 경기 초반 표본이며 모든 기기의 최소 성능을 뜻하지 않는다. 최종 카메라에 대한 다른 세 맵의 추가 성능 측정은 하지 않았다.

| 최종 환경 / 네온·3배속 | 평균 FPS | JS 평균 ms | 프레임 간격 p95 ms | 표본 프레임 |
|---|---:|---:|---:|---:|
| PC 1440×1000 | 45.0 | 5.78 | 33.4 | 195 |

## 발견한 실패와 수정

- 최초 동시 도착 테스트 fixture가 결승선에 닿지 않는 위치였음. fixture를 수정하고 통과.
- 긴 지그재그 맵의 경사 레일·범퍼 겹침으로 정체. 겹치는 범퍼 두 개를 열린 통로로 이동해 해결하고 120경기를 재검증.
- Node와 Chrome의 부동소수점 차이가 충돌 과정에서 확대되어 시드만으로 서로 다른 런타임의 동일 순서를 보장하지 못함. 같은 Chrome 재실행은 일치. 한계를 README에 기록했고 실패 로그도 보존.
- HTTPS Git push는 CLI 인증 부재로 실패. 사용자가 Fork 토큰 인증이라고 알려 준 뒤 Fork UI를 통해 일반 push 성공. 원격 main의 c7f1e00e74997027f34f6243a3d10ae6fe4fe79c 일치를 확인했다. CLI에 토큰을 복사하지 않았다. 후속 직접 main 커밋은 별도 Git 전달 기록에 남긴다.

## 미실행·한계

실제 iOS/Android 기기, Safari/Firefox, 사람의 음향 청취 평가, 전체 WCAG 감사, 통계적 당첨 확률 동등성, 네이티브 WebMCP, 외부 호스팅은 검증하지 않았다. 200% 확대 접근성 검증을 수행했다고 주장하지 않는다. 90초 제한의 미완주는 무효 처리하고 승자를 확정하지 않는다. 공은 같은 질량·크기를 사용하지만 완전히 동일한 당첨 확률은 보장하지 않는다.

스크린샷·브라우저 trace·설정/시드/결과 JSON·실행 명령은 evidence에 보존했다. `agent-session.md`는 실제 작업과 오류의 제출용 요약 로그이며 전체 채팅 원본이나 내부 추론 로그가 아니다.

최종 원근 3D 코드 커밋 `67a6e48`은 로컬 main과 원격 main이 일치함을 확인했다. [실제 Git 전달 기록](git-delivery.md)에 커밋·푸시 결과와 기존 파일 보존 검증을 기록했다.
