## 실제 CLI 전달 수정 · 2026-09-21

- 실제 마이크 로그에서 호출어 알림·명령 수집 성공을 확인. `TV TV 디아 진행해줘`, `헤이 TV 디아 작업 시작해줘`가 실행어로 처리되지 않았고, 반복 호출 시 기존 내용이 초기화되는 문제를 재현.
- 실행어에 진행/실행/작업 시작을 추가하고, 실행을 위한 반복 호출은 기존 명령을 보존하도록 수정.
- `--thread` 연결 모드 추가. 설치된 Codex CLI 0.155.1의 `codex queue --help`로 인터페이스를 확인. 기존 대화의 모델·권한을 유지하며 명령을 리터럴 인자로 전달.
- 수정·검증 1회. Swift 빌드·코드 서명·**44/44 자동 테스트 통과**. 실제 인식 문자열, 기존 명령 보존, 지정 대화로의 전달, 전달 실패, 전달/작업 완료 메시지 구분을 검사.
- 현재 대화에 코드 실행 없는 확인 메시지 한 건을 실제 전달하여 `Queued message … for thread …`, 종료 코드 0 확인.
- 현재 대화 ID를 명시한 `--thread` 모드로 마이크 대기를 재시작함. 이제 시작어를 말하면 현재 CLI 대화로 사용자 메시지가 접수되며, 대상 CLI의 작성 중 입력창에 초안을 타이핑하지는 않음.
- 재빌드 후 실제 실행 권한 조회에서 음성 인식·마이크가 모두 `notDetermined`(0)로 확인되어 권한 요청을 기다림. 이후 `마이크 준비 완료. 메뉴 막대의 “TBD · 호출 대기”에서 상태를 확인하세요.` 출력을 확인했으며, 현재 대화 연결 모드로 실행을 유지함.
