# 완료 범위·요청 시점 안내의 모바일 확인

root가 기존 http://127.0.0.1:5175/에 임시 탭14를 열어390×844로 확인했다. user-03을 선택한 뒤 완료 주문·요청 결과 탭을 각각 클릭했다. 새 주문·취소는 제출하지 않았다. 실제 수집 시각은 각 DOM JSON과 cleanup.json에 있으며 디렉터리 이름의 시각 부분을 수집 시각으로 대체하지 않는다.

closed-dom.txt와 closed.jpg에서 전역 완료200개 중 내 주문 최대20개·주문번호 기준 안내를 확인했다. requests-dom.txt와 requests.jpg에서 처리 당시 결과 안내 및 앞서 취소한116413의 기존 응답을 확인했다. 두 문구 모두 모바일 폭 안에서 줄바꿈하며 DOM의 documentWidth375≤viewport390이다. 목록은 기존 내부 스크롤을 사용한다. 실제 캡처한 이미지 범위 밖의 모든 기록이 한 화면에 보인다고 주장하지 않는다.

console.json의 warning/error는 빈 배열이다. cleanup.json은 탭14 닫기와 viewport 복원을 기록한다. 기존 사용자 탭·시장·Park 재시작은 없었다. 이는 새 문구의 dev UI 표시 확인이며 이전 모바일 거래 검증, frontend 빌드와 구분한다. API·주문 상태 계약은 바꾸지 않았다.
