# ATLAS — 도면에서 공간으로

한국의 공개 도면을 분석하고 WebGL로 탐험하는 로컬 연구용 앱입니다. 도면 라이브러리, 원본/3D 비교, 주차장 차량 이동과 화재 보행 대피를 제공합니다. 테마파크에서는 공사 중인 설계 연구소로 표시됩니다.

```sh
cd map
npm ci
npm run dev
```

로컬 주소: http://127.0.0.1:5185

## 화면과 조작

- **공간 탐색**: 첫 화면은 주소 마커가 있는 대화형 지도입니다. Google API 키가 있으면 Google WebGL 지도를 사용합니다. 42개 장소를 목록에서 선택하면 해당 원본 이미지의 벽체 후보를 추출해 3D로 엽니다. 키가 없으면 MapLibre와 OpenStreetMap으로 주소 마커·주소 라벨·유형별 WebGL 건물을 표시합니다.
- **도면 라이브러리**: 서울시 원본 10곳에 주차장 도면이 확인된 30곳(서울 15곳, 다른 지역 15곳)을 추가한 카탈로그입니다. 추가 도면의 시각 검토 근거와 설계자를 `public/plans/parking-sources.json`에 기록했습니다. 주차장 필터에는 추가 30곳과 다층 계획도 자료가 표시됩니다. 원본 출처·파일·SHA-256·수집 시각을 `public/plans/catalog.json`에서 확인할 수 있습니다. 별도로 동북권 세대융합형 복합시설의 실제 B2 주차장 PDF 16쪽도 분석할 수 있습니다.
- **실제 도면 주행**: B2 주차장 원본의 외곽·구획을 따라 작성한 주석 SVG에서 모델을 만들고, 램프부터 세 코어 접근 지점까지 차량으로 이동합니다. 차로와 접근 지점은 수동 주석이며 축척은 추정값입니다. 원본 PDF 자동 선 추출 결과와 구분됩니다. [원본·주석 근거](public/plans/PARKING-SOURCE.md)를 함께 확인할 수 있습니다.
- **주차장 시뮬레이션**: 기본은 실제 동북권 복합시설 B2 원본에 수동 주석한 동선을 사용합니다. 라이브러리에서 건물·층을 선택했다면 그 도면의 분석을 그대로 유지합니다. 차로 연결이 없는 원본에서는 자동 주행을 보류합니다. 원본 썸네일과 확대 보기, 3D 바닥 겹침으로 분석 결과를 비교할 수 있습니다. 목적지 동을 고르고 안내를 시작하면 차량이 경로를 따라 이동합니다. 1/3인칭, 좌·우회전 시 시선·위치 보간, 각도 경계에서 최단 방향 회전, 일시정지, 1/2/4배 재생, WASD/방향키 수동 이동을 지원합니다.
- **화재 모드**: 프로젝트 안내에서 여는 명시적인 합성 시험장에서만 제공합니다. 실제 B2 도면은 지상 대피 연결이 미확인입니다. 시험장에서는 움직이던 현재 위치를 경로에 연결하고 사람 모델로 전환합니다. 위험 반경과 가까운 구간의 위험 비용을 고려해 통과 가능한 외부 집결지로 이동합니다. 양쪽 출구를 차단하면 안내를 중지합니다. 소리 버튼으로 알림음·한국어 음성 안내를 켤 수 있습니다.
- **내 도면 가져오기**: PNG/JPEG, PDF 페이지, 주석 SVG, 분석 JSON을 로컬에서 처리합니다. 이미지 전체 너비를 입력하면 축척을 보정할 수 있습니다.
- **실차·충전 데이터**: [별도 카테고리](http://127.0.0.1:5185/mobility.html)에서 실제 도면·주행 궤적·제조사 제원·충전 자료 9개를 검색하고 출처와 확보 범위를 확인합니다. IONIQ 5·EV6의 차폭으로 실제 B2 도면의 동선 후보를 비교하고 충전기 설치 검토로 이동합니다. [자료 근거와 재현 절차](docs/MOBILITY-DATA.md), [전용 검증 보고서](http://127.0.0.1:5185/reports/mobility/)를 제공합니다.

## Google 지도 3D 연결

`map/.env.local`에 다음 값을 설정하고 서버를 다시 시작합니다. 이 파일은 Git에서 제외됩니다.

```dotenv
VITE_GOOGLE_MAPS_API_KEY=사용자_키
VITE_GOOGLE_MAPS_MAP_ID=벡터_맵_ID
```

Maps JavaScript API와 벡터 맵을 사용하며, 테스트에는 Google의 `DEMO_MAP_ID`도 지정할 수 있습니다. 키는 브라우저용이며 localhost HTTP referrer 제한을 권장합니다. 키가 연결되면 `WebGLOverlayView`가 지도 좌표에 3D 매스를 배치하고 클릭 가능한 건물 마커로 원본 분석에 연결합니다. 구현 근거: [Google 공식 WebGL 문서](https://developers.google.com/maps/documentation/javascript/webgl/webgl-overlay-view).

## 분석 SDK와 정확도

`src/core/analysis.js`는 브라우저와 Node에서 사용할 수 있는 JavaScript SDK입니다. `analyzeRaster(ImageData, options)`는 긴 어두운 직교 구조선을 추출합니다. `analyzeSvg(text)`는 `data-kind=wall/node/edge/space`와 축척이 있는 SVG를 읽습니다. `src/core/routing.js`는 차로 폭, 차량/보행 구분, 일방통행, 차단 구간, 화재 반경을 처리합니다.

실제 원본 도면의 글자·치수선이 벽체 후보에 포함될 수 있습니다. 축척·높이·문·계단·현재 시공 상태는 검토가 필요합니다. 지도 위치는 주소 조회 결과이며 대부분 도로·동·구 범위의 대표점입니다. 정확한 건물 좌표가 아닌 경우 화면에 표시합니다. `건물 매스` 화면은 동일 평면을 다섯 층으로 반복한 개념 모델입니다. 실제 주차장 동선과 시설별 소방 검증이 없는 원본에 임의의 안전 경로를 생성하지 않습니다. 주차장 시험장은 별도 합성 도면이며 실제 비상 안내 용도로 사용하지 않습니다.

렌더링은 실제 콘크리트 스캔의 색상·법선·거칠기 재질, 환경 반사, 부드러운 그림자, 접촉 음영을 적용합니다. 재질 출처와 CC0 이용 조건은 [재질 기록](public/materials/NOTICE.md)에 있습니다. 현장 사진이나 완성 BIM 모델을 확보한 상태는 아니며 차량에는 21만 삼각형의 Khronos CarConcept glTF 모델을 사용하고 기둥·배관은 절차적으로 생성합니다. 차량 출처와 CC BY 4.0 변경 기록은 [차량 자산 기록](public/models/NOTICE.md)에 있습니다.

아키스케치·오늘의집의 도면 검색은 로그인 기반 서비스여서 공개적으로 내려받을 수 있는 서울시 원본을 확보했습니다. 실제 단지의 주차장 원본이나 출입구 자료가 추가되면 해당 구조와 동선을 명시해 분석기에 입력할 수 있습니다.

macOS에서 PDF를 별도 이미지로 변환하려면:

```sh
swift -module-cache-path /tmp/atlas-swift-cache scripts/render-pdf.swift public/plans/changdong-parking-source.pdf 16 public/plans/changdong-parking-b2.png
```

## 검증과 보고서

```sh
npm run test:coverage
npm run build
# dev 또는 preview 서버를 실행한 상태에서:
npm run test:e2e
npm run reports
```

[HTML 보고서](http://127.0.0.1:5185/reports/index.html)는 핵심 SDK 커버리지와 Playwright 기능/골든 테스트를 연결합니다. 기준 화면은 `tests/e2e/golden`에 보관하며, 최초 생성 뒤 반드시 업데이트 옵션 없이 비교합니다. 스냅샷 갱신은 검토한 의도적 화면 변경에만 사용합니다.

## 자동 커밋·푸시

```sh
npm run checkpoint:watch
```

10분마다 `map` 변경을 확인하고, 커버리지·빌드·별도 포트 5187의 production E2E를 통과한 변경만 커밋한 뒤 푸시합니다. 다른 폴더의 변경은 스테이징하지 않습니다. 원격 공유 브랜치가 먼저 바뀌면 강제 푸시하지 않고 `map/checkpoint-<hash>` 브랜치로 체크포인트를 보존합니다. `.runtime/checkpoint.json`은 마지막 상태를 기록하며, 실행 여부는 기록된 PID의 실제 프로세스를 확인해야 합니다. Git 인증은 기존 로컬 credential 설정을 사용합니다.

## 충전기 설치 추천

전용 회로의 입력 여유 용량, 연결된 케이블 경로 길이, 사업자별 LTE RSRP, 입력 접근성 점수로 후보를 비교합니다. 배선 45%, 통신 30%, 접근성 25%의 비교 점수이며 전역 최적해를 보장하는 전기 설계 도구는 아닙니다. 여러 충전기를 선정할 때 같은 회로의 용량을 차감하고 다른 회로로 바뀌면 점수를 재계산합니다.

메뉴에서 선택한 실제 도면·층의 3D 분석 결과를 이어받습니다. 선택 전에는 실제 B2 도면으로 시작합니다. 원본을 바닥에 겹쳐 비교할 수 있으며 배선·용량·실측 신호가 없으면 추천을 보류합니다. **이 도면으로 충전기 설치 검토**도 같은 자료로 열립니다. 합성 EV 자료는 자동 로딩하지 않으며 테스트에서 명시적으로 사용합니다. **입력 형식**으로 도면 ID가 포함된 JSON 틀을 내려받고 현장 자료를 입력합니다. 좌표는 도면 중심 기준 미터(x,z), 배선은 nodes/cables 연결, 분전반·콘센트는 powerSources, 후보는 candidates, 실측은 signals에 기록합니다. `public/infrastructure/demo-survey.json`이 완성 예시입니다. 일반 콘센트와 검증되지 않은 회로는 충전기 전원으로 선정하지 않습니다.

신호 색상은 −115 dBm 이하 빨강 → −97.5 노랑 → −80 이상 초록입니다. 같은 사업자의 반경 22m 안 측정을 거리 역제곱으로 보간하고, 범위 밖은 회색으로 표시합니다. 이 구간은 앱의 비교 기준입니다.

`.env.local`에 서버 전용 `OPENCELLID_API_KEY`를 넣고 서버를 다시 시작하면 주변 공개 셀 기록을 조회할 수 있습니다. 키는 클라이언트에 포함하지 않습니다. 외부 지역 평균과 실제 주차장 내부 RSRP는 별도로 취급합니다. 현재 실제 시설 배선도·분전반 용량·실내 신호 실측 자료와 API 키는 제공되지 않았습니다. 이때 수치나 연결 위치를 추정하여 표시하지 않습니다. [OpenCellID API](https://docs.opencellid.org/docs/api/cells-in-area).

추가 30곳 원본 복원·해시 확인: `node scripts/acquire-parking.mjs`. 42곳의 주소 조회 결과는 `public/plans/locations.json`에 출처·범위·정확도와 함께 저장합니다. 대부분은 도로·동·구 대표 위치로서 정확한 건물 좌표가 아닙니다. 마커에서 주소 범위를 표시합니다. 마커를 누르면 지도 확대 및 상세 주소, 도면 열기 버튼을 사용할 수 있습니다. 아파트·공동주택/빌딩/대형건물/주택은 서로 다른 색상과 3D 형태를 사용합니다. 높이·외관은 유형별 개념 표현입니다.

주소 조회 도구는 단일 스레드, 1.1초 간격, 결과 저장 방식으로 일회성 실행합니다. 반복 실행은 이미 저장된 항목을 건너뜁니다. [Nominatim 이용 정책](https://operations.osmfoundation.org/policies/nominatim/)을 준수하고, 서비스 변경 시 `ATLAS_GEOCODER_URL`을 설정합니다. 조회 결과는 © OpenStreetMap contributors, ODbL 1.0입니다. 지도 타일도 OpenStreetMap 출처를 화면에 표시합니다.


## 지하층과 아파트 단지 자료

라이브러리에 **지하 1–4층**, **아파트 단지** 필터를 추가했습니다. 총 42곳·60장입니다.

- 도곡중 복합시설: 서울시의회 공개 계획 문서 17쪽에서 B1/B2/B3/B4 도면을 각각 분리했습니다. 동일 평면을 다른 층으로 복제하지 않습니다. 현재 시공 상태와 층간 차량 연결은 미확인입니다.
- 래미안 원펜타스: 공식 단지 배치도, 641세대·6개 동·지하 4층 규모 정보를 제공합니다. 지하 주차장 층별 평면도는 아직 확보하지 못해 B1~B4 버튼을 비활성화하고 이유를 표시합니다.
- LH 대단지 자료: 주차개요 합계 1,509대의 공동주택 BIM 설계 자료를 원문 PDF 12~14쪽과 램프 22쪽으로 연결합니다. 재배포 제한 때문에 원문 파일은 저장소에 포함하지 않습니다. 지명이 익명화되어 있으며 표고 LV를 임의로 B층 번호로 바꾸지 않습니다.

층별 선택은 원본·분석 결과·EV 입력 도면 ID를 함께 전환합니다. 다른 층의 조사 자료는 거부합니다. 원본·해시·추출 영역은 `public/plans/multilevel-sources.json`, 외부 참조는 `public/plans/complex-references.json`에서 확인할 수 있습니다.
