# 주행 영상 관찰과 적용

사용자가 제공한 [Reddit 게시물](https://www.reddit.com/r/NintendoSwitch/comments/1ukfdry/mario_kart_world_ver170_update_out_now_nintendo/?tl=ko)의 Mario Kart World ver. 1.7.0 업데이트 영상과 대응하는 [Nintendo UK 공식 영상](https://www.youtube.com/watch?v=XSEEnekrGsY)을 확인했습니다. 약 95초 영상의 6초 간격 프레임과 46–58초의 0.5초 간격 프레임을 직접 검토했습니다.

| 관찰 | 적용 |
|---|---|
| 낮은 뒤쪽 카메라, 원근이 강한 넓은 코스 | 주행 카메라 높이 4.4, 기본 FOV 62°, 확장 코스 및 가드레일 |
| 밝은 하늘과 먼 산·건물·나무, 노면 표시 | 하늘 그라데이션, 구름, 원경 안개, 6가지 테마 지형, 노면 텍스처·표지판 |
| 바퀴 근처 불꽃과 카트 기울기 | 곡률 기반 드리프트 자세, 회전 바퀴, 청색·황색 스파크 |
| 발사체가 이동한 뒤 충돌 | 명시적인 launch 로그, 0.7/0.9초 비행, 밝은 궤적과 발사 섬광 |
| 아이템별 다른 충돌 반응 | 원두 폭발, 얼음 파편, 다중 번개, 실드 충격파, 카트 스핀·점프 |
| 공격 순간 강한 시각·음향 피드백 | 시간 기반 카메라 반동, 콕핏 전환, 화면 주변 효과, 합성 발사·충격음 |
| 화면의 순위·속도·아이템 정보 | 순위·속도계·아이템 슬롯·실시간 미니맵 |

게임의 기존 커피·머리 아바타·자동 2바퀴 진행을 유지하면서 위 장면 구성을 적용했습니다. 자동차·트랙·배경·파티클은 코드로 생성합니다. 영상 파일은 참고 확인에만 사용했으며 프로젝트나 배포 결과물에 포함하지 않습니다. 원작과의 픽셀 일치 또는 동급 렌더링 품질을 측정한 것은 아닙니다. 골든 테스트는 이 구현의 회귀를 검증합니다.

## 시상대 스폰서 사진 관찰

사용자가 지정한 [연합뉴스의 2013 넥센타이어 시상대 사진](https://www.yna.co.kr/view/AKR20130419105200007)을 확인했습니다. 상단의 큰 행사명, 뒤쪽 전체를 덮는 흰색·색상 격자 스폰서 월, 2·1·3 순서의 높이가 다른 흰색 시상대와 붉은 바닥 구성을 참고했습니다.

게임에는 **52G · 2026 해커톤** 행사명과 청록색·흰색 반복 로고 월을 직접 그립니다. 사진 파일은 게임에 포함하지 않습니다. 기존 트로피 상승과 참가자 순위는 유지하고, 독립된 작은 양옆 광고판을 전체 배경 벽으로 바꿨습니다.

맵의 회사 광고는 주변 구조물의 간판으로 배치합니다. 도시는 외벽 전광판·옥상 광고판, 로스터리는 카페, 해변은 상점, 숲은 목조 휴게소, 설원은 산장, 화산은 에너지 시설입니다. 건물은 도로를 향하며 노면과 다른 광고 건물에서 이격하고, 해당 자리에는 기존 나무·일반 건물이 생성되지 않습니다.

## 사업별 3D 건물

추가 요청에 따라 간판만 다른 공통 건물에서 사업별 시설 모델로 확장했습니다. 충전소의 충전 구획·전기차·케이블, 주유소의 주유기·호스·캐노피, GS25의 상품 진열창·입구·테라스, GS건설의 층별 골조·타워 크레인·현장 가림막, GS에너지의 태양광·저장 캐비닛·탱크, GS EPS의 LNG 탱크·발전 스택·터빈, GS글로벌의 물류창고·컨테이너·트럭, GS그룹의 유리 로비·복합 사옥을 직접 모델링했습니다. 실재 시설의 정밀 복제나 설계도가 아닌 게임용 사업 이미지입니다.

각 맵에 맞는 재료와 지붕·부대 요소를 적용하고, 도로 중심선에서 부지 중심까지 최소 24, 광고 시설끼리 중심 간격 24 이상을 확보합니다. 정적 지형과 함께 재질별로 병합해 렌더링합니다. 실제 3D 모델의 개별 캡처와 치수·구성 목록을 `reports/sponsors/buildings/`와 `buildings.json`에 저장합니다.
