# BREW RACERS ☕

목소리로 입장하고, 두 바퀴 자동 카트 레이스로 오늘 커피를 살 사람을 정하는 WebGL 게임입니다. 우승자는 시상대에서 황금 트로피를 받고, 9초 뒤 꼴찌가 커피차의 바리스타가 되어 웃는 친구들에게 커피를 나눠 줍니다. “달다 달아 이썩겠네.” 멘트와 함께 커피를 만든 뒤 반복 하이라이트가 이어집니다.

## 실행

Node.js 22.12 이상, Google Chrome을 권장합니다.

```sh
npm install
npm run dev
```

터미널에 표시된 주소를 여세요. `127.0.0.1:5173`부터 실제 포트 바인딩을 시도하고, 사용 중이면 5174, 5175 순서로 빈 포트를 선택합니다. `PORT=6000 npm run dev`로 시작 포트를 지정할 수 있습니다. 마이크는 localhost 또는 HTTPS에서 사용할 수 있습니다.

첫 방문에는 **체험 멤버 4명**이 있습니다. `체험 멤버 비우기` 후 실제 참가자를 등록하세요. 마이크 없이 직접 입력하거나 체험 레이스를 할 수도 있습니다. 참가자는 2–8명입니다.

## 기술 선택

React·TypeScript는 화면과 상태를, Three.js는 WebGL GPU 렌더링을 담당합니다. Python 서버나 외부 모델 다운로드 없이 실행합니다. 짧은 고정 스텝 시뮬레이션으로 레이스를 미리 계산하고 렌더링에서 상태를 보간합니다. 로그를 읽을 때 다시 랜덤 계산하지 않아 결과와 이벤트를 그대로 재생합니다.

렌더 루프는 React 상태 갱신과 분리했습니다. UI는 약 10Hz, 로비는 최대 24Hz로 갱신하며 모달 뒤의 정지 장면은 다시 그리지 않습니다. 픽셀 비율은 최대 1.5이고 프로필 썸네일은 재사용합니다. 모션 감소 설정을 지원하며 글꼴도 로컬 패키지로 제공해 외부 요청이 없습니다.

## 레이싱 연출

[Mario Kart World ver. 1.7.0 공식 영상](https://www.youtube.com/watch?v=XSEEnekrGsY)의 주행·아이템 장면을 참고해 코스 폭과 원경, 낮은 추적 카메라, 드리프트 불꽃과 아이템 피격 반응을 강화했습니다. 영상의 프레임 관찰 기록은 `docs/reference-study.md`에 있습니다.

- 주행: 넓은 텍스처 노면, 가드레일·방향 표지·구름·산·6가지 배경, 회전하는 바퀴, 코너 기울기·스파크, 속도계·미니맵.
- 발사: 원두·얼음은 0.9초, 번개는 0.7초 비행 후 충돌합니다. 궤적·발사 섬광·카메라 반동·상승 효과음이 함께 재생됩니다.
- 피격: 1인칭 콕핏, 카트 회전·점프, 충격파·파편·번개, 화면 가장자리 색상·짧은 섬광·저음 충격음. 실드는 충돌 시점에 판정합니다.
- 부스트: 양쪽 배기 불꽃과 속도선, 넓어지는 시야각과 상승 효과음.
- 재생: 모든 3D 효과는 로그 시각으로 계산해 일시정지와 되감기에도 같은 장면을 보여줍니다. 예전 로그에는 발사 연출을 추론해 적용합니다. 모션 감소 설정에서는 카메라 흔들림·속도선·섬광을 끕니다.
- 성능: 정적 지형 메시를 재질별로 합치고 최대 1,000개 파티클을 인스턴싱해 그립니다. 실제 콘솔 원작과 동일한 그래픽 품질을 보장하는 구현은 아닙니다.

## 캐릭터·음악·시상식

프로필을 눌러 Nintendo 캐릭터 8종 중 하나를 고릅니다. 목소리로 배정한 보이스 무드와 캐릭터 선택은 별도로 보존됩니다. 캐릭터는 직접 만든 3D 두상이며 공식 게임의 원본 모델 파일은 사용하지 않습니다.

배경음은 첫 클릭 또는 키 입력 후 시작합니다. 상단 사운드 버튼으로 배경음과 효과음을 함께 끄고 켤 수 있으며 설정은 다음 방문에도 유지됩니다. 일시정지·음성 입력·다른 탭으로 이동할 때 소리가 멈춥니다. 음악은 Web Audio로 연주하는 자체 제작 8마디 반복곡이며, Nintendo 게임 음악을 사용하지 않습니다. 마지막 바퀴에서는 템포가 빨라지고 우승·커피 멘트가 나올 때 음악 음량을 낮춥니다.

레이스 종료 시 **실제 1위**가 시상대 중앙에서 트로피를 받습니다. 2명이 참가하면 1·2위만 표시합니다. 약 9초 후 꼴찌의 커피차 장면으로 전환됩니다. 커피차에서는 나머지 참가자가 웃으며 차례로 커피를 받습니다. 참가자 수에 따라 12–24초 뒤 반복 하이라이트로 이어지고, `하이라이트 보기`로 바로 넘어갈 수 있습니다. 시상식도 일시정지할 수 있고, 결과 화면의 `시상대 다시 보기`와 `커피차 다시 보기`로 각 장면을 다시 재생합니다. 모션 감소 설정에서는 트로피를 올린 정지 자세를 보여 줍니다.

트랙에는 GS차지비·GS그룹·GS칼텍스·GS리테일·GS건설·GS에너지·GS EPS·GS글로벌의 광고와 사업별 건물을 배치했습니다. GS차지비는 전기차·충전기가 있는 충전소, GS그룹은 유리 로비와 외벽 광고가 있는 사옥, GS칼텍스는 주유기·캐노피가 있는 주유소, GS리테일은 상품 진열창·테라스가 있는 GS25 편의점입니다. GS건설은 크레인·골조·현장 가림막, GS에너지는 태양광·전력 저장 설비, GS EPS는 LNG 탱크·발전 설비, GS글로벌은 물류창고·컨테이너·트럭으로 구분합니다.

도시의 높은 사옥과 외벽 전광판, 해변의 밝은 외장, 숲의 목재, 설원의 눈 덮인 지붕, 화산의 산업용 재료로 맵 분위기를 반영합니다. 간판은 캐노피·외벽·옥상·현장 가림막 등 실제 구조물에 부착하고, 건물 부지와 도로·인접 건물의 간격을 검사합니다. 광고에는 회사별 사업 그림과 문구를 넣으며, 판의 가로세로 비율에 맞게 그려 글자와 그림이 늘어나지 않도록 합니다. 커피차 뒤 GS차지비·GS그룹 보드에도 같은 광고를 사용합니다.

우승 시상대 뒤에는 [참고 사진](https://www.yna.co.kr/view/AKR20130419105200007)처럼 상단 행사명과 반복 격자로 구성한 **52G · 2026 해커톤** 스폰서 월을 배치했습니다. 흰색 시상대와 붉은 바닥이 배경과 연결됩니다. 광고와 스폰서 월은 CanvasTexture로 직접 그리며 외부 이미지를 요청하지 않습니다. 계열사 이름은 [GS그룹 공식 계열사 소개](https://www.gs.co.kr/ko/about-gs/subsidiaries), 52G 표기는 [52g 공식 사이트](https://www.52g.gs/)를 참고했습니다. 행사 문구는 사용자가 요청한 내용입니다.

## 음성 기능의 범위

- **화자 구분은 실험적인 로컬 특징 비교입니다.** 주기성 기반 음높이와 12차 멜 대역 켑스트럼 특징을 비교합니다. 음성 프레임이 부족하면 등록을 거절하고, 유사도 또는 후보 간 차이가 부족하면 직접 선택을 요청합니다. 학습된 화자 임베딩 모델이나 보안 인증 기능은 아닙니다. 비슷한 목소리·문장·소음·마이크 변경에 영향을 받습니다.
- **연예인 배정은 재미용 보이스 무드입니다.** 실제 연예인 음성 데이터로 신원을 식별하지 않습니다. Nintendo 아바타는 실제 인물의 얼굴 복원이 아닙니다.
- 녹음과 특징은 이 브라우저에 저장합니다. 별명·음료 받아쓰기는 브라우저 제공업체 서버에서 처리될 수 있으며 네트워크와 브라우저 지원이 필요합니다. 화면에서 안내하고 직접 입력도 제공합니다.
- 마이크 거부, 무음, 불충분한 녹음, 받아쓰기·저장·WebGL 오류를 처리합니다. 프로필에서 녹음을 다시 들을 수 있습니다.

## 검증·보고서

개발 서버를 실행한 뒤:

```sh
npm run build
npm run test:coverage
npm run test:e2e
npm run test:golden
npm run reports
```

포트가 달라지면 `TEST_URL=http://127.0.0.1:5174 npm run test:e2e`로 지정합니다. Playwright는 설치된 Google Chrome을 사용합니다.

- `reports/index.html`: 전체 결과와 한계
- `reports/unit/index.html`: 단위 검사 및 원본 JSON
- `reports/coverage/index.html`: 엔진·연출 시간축·음성·저장·음악·음향 제어 모듈 커버리지 (UI·WebGL 제외)
- `reports/e2e/index.html`: 실제 브라우저 시나리오, 실패 시 스크린샷·trace
- `reports/golden/index.html`: 화면 비교 및 기준 이미지
- `reports/build/index.html`: 빌드·포트·의존성 검사
- `reports/audio/index.html`: 실제 Web Audio 출력 측정과 음악·효과음 WAV 듣기
- `reports/characters/index.html`: Nintendo 두상 선택 화면과 검증 범위
- `reports/podium/index.html`: 데스크톱·휴대폰 우승 시상대와 검증 범위
- `reports/coffee/index.html`: 커피차 연출, 손님 배정·주문 전달·멘트·자동 전환 검사
- `reports/sponsors/index.html`: 광고 배너·시상대 스폰서 연출과 명칭 참고 자료
- `reports/replay-example.json`: 검사에서 생성된 레이스 로그
- `tests/unit/__snapshots__/race.test.ts.snap`: 시뮬레이션 골든
- `tests/e2e/golden.spec.ts-snapshots/`: 화면 골든 기준

화면 변경을 의도한 경우에만 `npm run test:golden -- --update-snapshots`로 기준을 생성하고 직접 검토하세요. 이후 `npm run preview -- --port 5175`로 빌드 서버를 실행하고 `npm run test:golden`으로 별도 비교합니다. 골든 전용 설정은 개발 서버 HMR의 자동 새로고침을 피하기 위해 기본적으로 `http://127.0.0.1:5175`를 사용합니다. 빌드 서버가 다른 포트를 선택하면 `TEST_URL`로 해당 주소를 지정하세요. 독립 비교 원본과 Playwright HTML은 `reports/golden/comparison/`에 저장합니다. `npm run reports -- --publish`는 보고서를 `dist/reports/`에도 복사합니다.

음성 브라우저 검사는 합성 오디오와 모의 받아쓰기 응답을 사용해 실제 Web Audio·MediaRecorder·IndexedDB·화자 선택을 실행합니다. 실제 사람의 인식 정확도나 STT 제공업체 품질은 자동 검증하지 않았습니다. 픽셀 골든은 현재 환경의 회귀 검사입니다.

이전 그래픽 변경에서 **정지·되감기 전후 화면의 엄격한 픽셀 비교 1개**가 같은 장애 3회로 중단되어 미해결 상태입니다. 이번 추가 기능 검증은 `npm run test:e2e -- --grep-invert 'deterministic pause'`로 해당 검사만 제외하고 실행합니다. 실패 증거는 `reports/replay-debug/`, 앞선 검사 기록은 `docs/graphics-verification.json`에 보존했습니다. 전체 프로젝트 검증 완료로 표시하지 않습니다.

```text
tests/e2e/      브라우저 시나리오·화면 골든
scripts/        빈 포트 실행, 캡처, HTML 보고서
reports/        실행 결과와 증빙
```

## 참고·라이선스

밝은 트랙과 작은 카트의 시각적 방향은 [Nintendo Mario Kart 8 Deluxe 공식 사이트](https://mariokart8deluxe.nintendo.com/)를 참고했습니다. 자동차·배경은 직접 구현하고, 요청한 Nintendo 캐릭터는 Three.js 지오메트리로 재구성했습니다. 원본 게임 모델·텍스처·음원 파일을 추출하지 않았습니다.

[Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html), [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [MDN Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API)를 참고했습니다. 글꼴은 Barlow Condensed, DM Sans, Noto Sans KR의 OFL 패키지이며 개별 LICENSE는 node_modules 내 해당 패키지에 포함됩니다. 아이콘은 Lucide입니다.

배포용 서드파티 라이선스는 `public/THIRD_PARTY_NOTICES.txt`에 포함되며 빌드 시에도 복사됩니다. 프로덕션 UI 브라우저 검사는 `npm run preview -- --port 5175 --strictPort` 실행 후 `npm run test:e2e -- --config=playwright.production.config.ts --grep-invert 'deterministic pause'`로 재현합니다. 음향 샘플 렌더 검사 1개는 개발 서버에서 소스 모듈을 직접 가져오므로 기본 5173에 접속합니다. 다른 개발 포트는 `AUDIO_TEST_URL`로 지정합니다. 이 서버를 함께 켜 두면 프로덕션 설정에서도 해당 검사를 포함할 수 있습니다.
