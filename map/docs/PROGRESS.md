# 구현 및 검증 기록

## 1회차 — 원본 수집과 SDK

- 서울시 공동체주택 플랫폼의 이미지 파일을 직접 내려받고 SHA-256을 기록함.
- 서로 다른 게시물이 동일 건물인 온음 중복 항목을 주소로 걸러냄. 좌표가 없는 항목도 교체함.
- SDK 단위 테스트 17개 통과. 라인 100%, 함수 100%, 분기 94.39%, 구문 99.45%.
- `8ed94d2`: 원본 카탈로그·분석 SDK·길찾기 커밋.
- 원격의 병행 pinball 작업으로 push가 거절되어 원격 이력을 보존하며 병합. `d5796af`까지 origin/main 푸시 성공.

## 2회차 — WebGL 앱과 브라우저 검증

- 원본 이미지 분석, 평면/매스, 지도, 주차장 차량 이동, 현재 위치에서 사람 대피, 음성 안내 구현.
- 초기 실제 Chrome 캡처에서 JavaScript 실행 오류 0개 확인.
- 동 입구 경로 끝이 코어 내부에 겹친 문제를 발견해 건물 전면 정차 위치로 조정.
- 초기 모델의 과한 밝기를 줄이고 카메라 구도를 조정함.
- 실제 지하 주차장 PDF 확보, PDF.js 페이지 분석과 macOS PDFKit 전처리 추가.
- 기능/E2E/골든 기준 생성 진행 중. 아직 최종 회귀 비교가 완료된 상태는 아님.

## 3회차 — 브라우저 실패 원인 수정

- 회색 스캔 도면에서 벽을 찾지 못해 명암 임계값을 단계적으로 조정하고, 도면 테두리 제거 조건을 수정함.
- 초기화 직후 목적지를 바꾸면 이전 비동기 로딩이 선택을 덮는 문제를 수정함. 로딩 동안 목적지와 시작 버튼을 잠금.
- PDF 첫 실행 시 개발 서버 의존성 최적화가 페이지를 다시 불러오는 문제를 확인하고 PDF.js 사전 최적화를 설정함. production 서버에서도 확인함.

## 4회차 — 실사 재질과 production 검증

- 실제 콘크리트 스캔의 색상·법선·거칠기 텍스처, 환경 반사·그림자·접촉 음영 적용. 정적 모델은 재질별로 병합해 draw call을 줄임.
- production 브라우저 기능 7개 통과. 골든 이미지 6개 생성. 이 실행은 기준 생성이므로 최종 회귀 비교 통과로 처리하지 않음.
- 테마파크 레지스트리 테스트 42개 및 루트 빌드 통과. map 어트랙션의 construction 상태와 실행 가능 여부를 API로 확인함.

## 5회차 — 실제 주차장 주석 기반 주행

- 실제 B2 도면 좌표를 따라 외곽·구획을 주석 SVG로 기록함. 추정 축척과 수동 지정 차로를 화면과 출처 문서에 명시함.
- 램프 입구에서 세 코어 접근 지점으로 차량 이동을 연결함. 미확인 지상 출구는 생성하지 않음.
- 새 단위 테스트의 좌표 비교 실패는 소수점 환산 오차였음. 부동소수점 허용 오차 비교로 수정함.
- 단위 테스트 20개 통과. 라인 100%, 함수 100%, 분기 94.01%, 구문 99.5%. production 빌드 통과.
- 실제 도면 주행을 포함한 브라우저 테스트 8개 및 최종 골든 비교 진행 중.

## 유지하는 미검증 범위

- Google Maps JavaScript API 키가 없어 실제 WebGL 지도 연결은 실행 검증 전. 키 없는 기본 화면은 실제 Google 임베드 지도.
- 실제 주차장 도면의 출입문·방화구획·지상 대피소까지 연결된 승인 동선은 미확보. 실제 도면 주행은 수동 주석의 근사 경로이며 대피 검증은 명시적 시험장 도면에 대해 수행.
- 자동 저장 프로세스, 최종 HTML 보고서·골든 비교 검증을 계속 진행.

사용자 변경 사항: 같은 장애 3회 반복 시 중단 대신 접근 방식을 변경. 중간 커밋마다 자동 푸시. 길찾기는 실제 이동 애니메이션. 선택 가능한 사항은 자동 판단. 렌더링은 최대한 실사에 가깝게 개선.
