# 구현 및 검증 기록

## 1회차 — 원본 수집과 SDK

- 서울시 공동체주택 플랫폼의 이미지 파일을 직접 내려받고 SHA-256을 기록함.
- 서로 다른 게시물이 동일 건물인 온음 중복 항목을 주소로 걸러냄. 좌표가 없는 항목도 교체함.
- SDK 단위 테스트 17개 통과. 라인 100%, 함수 100%, 분기 94.39%, 구문 99.45%.
- `8ed94d2`: 원본 카탈로그·분석 SDK·길찾기 커밋.
- 원격의 병행 pinball 작업으로 push가 거절되어 원격 이력을 보존하며 병합. `d5796af`까지 origin/main 푸시 성공.

## 2회차 — WebGL 앱과 브라우저 검증

- 원본 이미지 분석, 평면/매스, 지도, 주차장 차량 이동, 현재 위치에서 사람 대피, 음성 안내 구현.
- 초기 실제 Chrome 캡처에서 JavaScript 실행 오류 0개 확인.
- 동 입구 경로 끝이 코어 내부에 겹친 문제를 발견해 건물 전면 정차 위치로 조정.
- 초기 모델의 과한 밝기를 줄이고 카메라 구도를 조정함.
- 실제 지하 주차장 PDF 확보, PDF.js 페이지 분석과 macOS PDFKit 전처리 추가.
- 기능/E2E/골든 기준 생성 진행 중. 아직 최종 회귀 비교가 완료된 상태는 아님.

## 3회차 — 브라우저 실패 원인 수정

- 회색 스캔 도면에서 벽을 찾지 못해 명암 임계값을 단계적으로 조정하고, 도면 테두리 제거 조건을 수정함.
- 초기화 직후 목적지를 바꾸면 이전 비동기 로딩이 선택을 덮는 문제를 수정함. 로딩 동안 목적지와 시작 버튼을 잠금.
- PDF 첫 실행 시 개발 서버 의존성 최적화가 페이지를 다시 불러오는 문제를 확인하고 PDF.js 사전 최적화를 설정함. production 서버에서도 확인함.

## 4회차 — 실사 재질과 production 검증

- 실제 콘크리트 스캔의 색상·법선·거칠기 텍스처, 환경 반사·그림자·접촉 음영 적용. 정적 모델은 재질별로 병합해 draw call을 줄임.
- production 브라우저 기능 7개 통과. 골든 이미지 6개 생성. 이 실행은 기준 생성이므로 최종 회귀 비교 통과로 처리하지 않음.
- 테마파크 레지스트리 테스트 42개 및 루트 빌드 통과. map 어트랙션의 construction 상태와 실행 가능 여부를 API로 확인함.

## 5회차 — 실제 주차장 주석 기반 주행

- 실제 B2 도면 좌표를 따라 외곽·구획을 주석 SVG로 기록함. 추정 축척과 수동 지정 차로를 화면과 출처 문서에 명시함.
- 램프 입구에서 세 코어 접근 지점으로 차량 이동을 연결함. 미확인 지상 출구는 생성하지 않음.
- 새 단위 테스트의 좌표 비교 실패는 소수점 환산 오차였음. 부동소수점 허용 오차 비교로 수정함.
- 단위 테스트 20개 통과. 라인 100%, 함수 100%, 분기 94.01%, 구문 99.5%. production 빌드 통과.
- 실제 도면 주행을 포함한 브라우저 테스트 8개 및 최종 골든 비교 진행 중.

## 유지하는 미검증 범위

- Google Maps JavaScript API 키가 없어 실제 WebGL 지도 연결은 실행 검증 전. 키 없는 기본 화면은 MapLibre/OpenStreetMap 주소 지도이며 40곳의 마커·유형별 3D 모델을 표시함.
- 실제 주차장 도면의 출입문·방화구획·지상 대피소까지 연결된 승인 동선은 미확보. 실제 도면 주행은 수동 주석의 근사 경로이며 대피 검증은 명시적 시험장 도면에 대해 수행.
- 자동 커밋 프로세스 및 최종 HTML 보고서·골든 비교 결과는 아래 최신 검증 기록을 기준으로 함.

사용자 변경 사항: 같은 장애 3회 반복 시 중단 대신 접근 방식을 변경. 중간 커밋마다 자동 푸시. 길찾기는 실제 이동 애니메이션. 선택 가능한 사항은 자동 판단. 렌더링은 최대한 실사에 가깝게 개선.

- `97a74e4` 앱·실제 주차장 주석·PBR 렌더링 커밋 후 origin/main 푸시 완료.

## 추가 요청 검증 1회차 — 렌더링·충전기 추천·30곳 확장

- Khronos CarConcept 모델, 유리·도장·환경 반사, 4096 그림자, 에폭시 마감 재질 적용.
- 충전기 추천 카테고리, 연결된 케이블 최단 경로, 공유 전원 용량 차감, RSRP 그라데이션, 콘센트 표시, 현장 자료 가져오기, OpenCellID 서버 어댑터 구현.
- 공개 도면 후보 113곳 중 주차 구획/주차장 범례가 확인된 30곳을 채택. 서울 15곳 및 다른 지역 15곳, 원본 도면 32장. 기존 10곳과 합쳐 40곳/55장.
- 실제 도면에서도 EV 검토를 열되 현장 자료가 없으면 추천과 인프라를 비워 둠. 초기에는 정밀 좌표가 없는 새 항목에 마커를 만들지 않았으나, 후속 주소 마커 요청에서 주소 범위 대표점과 정확도 표기로 확장함.
- 첫 확장 검증에서 기존 원본 테스트가 카탈로그 10곳만 가정해 실패. 원본 10곳의 검증을 유지하며 신규 30곳 검증을 분리함.

## 추가 요청 검증 2회차 — 회로·사업자·출처 검증

- 다른 회로를 사용하게 되면 케이블 길이 점수를 다시 계산하고 통신 사업자 자료를 섞지 않음.
- 단위 테스트 35개 통과, 핵심 SDK 라인/함수 100%, 구문 99.42%, 분기 95.61%.
- 전체 40곳 브라우저 구조선 변환 통과. 전체 기능 및 골든 검증 계속 진행 중.
- 현장 배선/실내 통신은 미확보 상태를 유지. OpenCellID 키 미설정 시 서버 503 메시지 확인.

자동 승인 요청: 설치 CLI는 `--auto-approve` 대신 `--approve-for-me`를 지원함. 현재 대화의 권한 프로필을 바꾸는 도구가 없어 실제 전환했다고 보고하지 않음. 사용자가 허가한 구현·테스트·범위 제한 커밋·푸시는 계속 진행.


## 추가 요청 검증 3회차 — 입력과 지도 초기화

- 고부하 브라우저에서 짧은 키 입력이 렌더링 프레임 사이에 사라지는 원인을 확인. 최초 keydown에 한 번 이동 업데이트를 적용하고 키보드 E2E 재검증 통과.
- 키 없는 지도에도 저장된 40개 주소를 표시하도록 MapLibre와 유형별 WebGL 모델을 추가. 좌표의 대부분은 주소 범위 대표점이며 정밀 건물 위치로 표시하지 않음.
- 공통 건물 모듈이 진입점의 top-level await와 순환 의존을 만든 문제를 전용 청크로 분리. 지도 초기화 중단 해결.

## 추가 요청 검증 4회차 — 실제 지도 표시 및 1인칭 회전

- 지도와 기존 3D 캔버스가 겹쳐 마커/상세창을 가리던 초기 화면 전환을 수정. 지도 컨테이너 위치를 명시하고 초기 setScreen으로 가려진 캔버스를 비활성화.
- 실제 Chrome 캡처에서 주소 마커 40개, 건물 모델 40개, 유형 4개, JavaScript 오류 0개 확인.
- 1인칭 방향 전환에 최단 각도 보간과 초당 1.9 rad 회전 제한 적용. 카메라 위치도 보간해 좌·우회전 직후 시점 점프를 줄임.
- 카메라 단위 테스트(좌/우 단조 회전, ±180도 경계, 프레임 간격) 추가. 전체 단위 테스트 39개 및 production 빌드 통과. 브라우저 기능·골든 회귀 비교 진행.
- 골든 테스트 기본값을 갱신 금지로 고정. HTML 보고서도 업데이트 없이 전체 13개 테스트가 통과한 결과만 완료로 표시.

- 추가 브라우저 확인: 주소 지도 40개 마커·4유형 진입 통과, 충전기 데스크톱/모바일 기준 이미지 생성, 좌·우회전 카메라 통과.
- 카메라 테스트의 최초 실패는 650ms 동안 소프트웨어 렌더링 프레임이 한 번만 기록된 것이 원인. 좌/우 각각 6개 실제 프레임을 수집하도록 수정해 통과. 동작 구현과 허용 오차는 변경하지 않음.
- 이 단계는 중간 체크포인트이며 전체 13개 무갱신 회귀 비교와 최종 HTML 완료 판정은 다음 검증에서 수행.
- 후속 요청: 지하 B1/B2/B3/B4 원본 및 대형 아파트 단지 지하주차장 도면을 조사·추가. 단계별 커밋 즉시 푸시.
