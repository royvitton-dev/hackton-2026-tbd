# 실차 경로·충전 데이터 카테고리

주소: <http://127.0.0.1:5185/mobility.html>. ATLAS 상단의 **실차·충전 데이터** 메뉴에서 엽니다.

출처별 9개 자료를 도면·실제 주행, 차량 제원, 충전 위치·수요로 나눕니다. 검색, 출처 상세, 확보 상태, 원문 링크, 현재 검색 결과의 JSON 내보내기를 제공합니다. 원문 확인일은 2026-09-21입니다. `public/mobility/catalog.json`에 수치·출처·권리·확보 범위를 보관합니다.

## 확인한 데이터

- **Palo Alto 3606 El Camino Real**: [시청 공개 설계안](https://www.paloalto.gov/files/assets/public/v/1/planning-amp-development-services/new-development-projects/3606-el-camino/c1_3606ecr_plan.pdf#page=10)의 PDF 10쪽, AP0.10, 2024-05-31. 1·2층 차로, 램프, EV 주차면, 벽부형 충전기와 접근성 상세를 PDF 렌더링으로 확인했습니다. EV Charger 41면, 일반 EV 주차면 9×18ft를 사실값으로 기록했습니다. 설계자의 복제 제한 표기가 있어 원문 PDF·이미지를 배포하지 않고 링크·확인한 파일의 SHA-256만 저장합니다. 계획 위치이며 시공 상태나 최적 위치의 증거가 아닙니다.
- **DLP**: [Berkeley / Dryad](https://datadryad.org/dataset/doi:10.5061/dryad.tht76hf5b)의 실제 실외 주차 궤적 데이터. 데이터는 CC0, 별도 API 도구는 GPL-3.0입니다. JSON 직접 다운로드가 403 응답으로 제한되어 확보했다고 표시하지 않습니다.
- **IONIQ 5 / EV6 Type A**: 현대 호주 제원 PDF 2쪽과 기아 인도용 영문 사용설명서의 차량 크기. 서로 다른 시장·등급을 혼합하지 않습니다. EV6 회전 원은 해당 설명서에서 확인하지 못했으므로 `null`입니다. 제조사 전폭을 미러 포함 폭이라고 가정하지 않습니다.
- **한국환경공단**: 전국 충전소·출력·상태·층수 정보. 서비스 키가 필요하며 도면의 주차면 좌표를 제공하는 것으로 표시하지 않습니다.
- **ACN-Data / ACN 전력망 연구**: 실제 충전 세션과 전력 제약을 별도 자료로 분류했습니다. 해외 시설의 수요·전력망을 국내 B2 실측으로 합치지 않습니다.
- **AFDC**: 충전 네트워크별 시설 위치·수집·갱신 정보를 연결합니다.
- 기존 **동북권 B2 원본**도 새 카테고리에서 접근할 수 있습니다.

## 차폭 기반 동선 후보

기존 `changdong-parking-annotated.svg`의 그래프와 원본 이미지의 동일 crop을 사용합니다. 차종·목적지·편측 여유 폭을 선택하면 차폭+양측 여유 폭보다 좁은 간선을 제외하고 경로를 다시 계산합니다. 기존 차로 최소 폭 2.5m도 유지합니다. 후보가 없으면 재생을 비활성화합니다. 차량 도형은 실제 제원의 전폭·전장을 반영합니다.

차로는 수동 주석이고 축척 0.09m/px는 추정값입니다. 중심선 경로에 대한 차폭 검사이며 조향 곡률·차체 회전 영역·벽체 충돌·승하차 공간의 검증이 아닙니다. IONIQ 5 최소 회전 원 지름 11.98m를 후륜 차축 중심의 회전 반경으로 변환해 경로 제약에 쓰지 않습니다.

‘B2 충전기 설치 검토’는 기존 실제 도면 작업 화면으로 연결합니다. 전용 회로, 배선, 실측 통신과 설치 공간 자료가 없으면 기존 추천기가 후보를 선정하지 않습니다. 다른 시설의 데이터로 채워진 가짜 실측 예시는 자동 주입하지 않습니다.

## 재현

```sh
cd map
npx vitest run --coverage --config vitest.mobility.config.mjs
npm run build
npx playwright test --config playwright.mobility.config.mjs
node scripts/report-mobility.mjs
```

전용 HTML 보고서: <http://127.0.0.1:5185/reports/mobility/>. 기존 지도 작업의 보고서를 덮어쓰지 않고 신규 핵심 모듈과 카테고리 브라우저 검증을 분리해 보관합니다. 신규 화면 기준 변경 시 `--update-snapshots=all`로 생성·시각 검토한 뒤 옵션 없이 독립 비교합니다.
