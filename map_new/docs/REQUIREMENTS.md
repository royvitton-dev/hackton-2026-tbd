## 외부 조건

Google/Kakao 키는 최초 조사에서 없었으며 사용자에게 로컬 설정 가능 여부를 질문했다. 실제 B2 공개 계획도에는 지상 대피소까지의 검증된 연결과 실측 축척이 없다. 확인되지 않은 위치·출구·EV를 실제 시설로 표시하지 않는다. 합성 시험 결과를 실제 시설 검증으로 집계하지 않는다.

## 현재 직접 확인한 근거

- `public/sources/catalog.json`: 서로 다른 실제 장소 45곳·9개 유형·공개 원본 63장, 원본 파일 해시와 발행처. B2 PDF와 도면·주차 레이어를 보존.
- `public/generated/*.json`: 인덱스 삼각형 벽체 메시, 노드·그래프·주차면, 원본/주석 해시.
- `src/core/layers.js`: 명시적인 2D 차로 선의 교차점·목적지에서 Node/Graph 자동 생성. 원본 경계·차로의 추적 단계는 분석가 작업.
- `public/sources/neonadeuli-osm.xml` → `scripts/extract-osm.py`: 실제 OSM 주변 도로 9개와 건물 윤곽 1개. 공개 평면도에 있는 진입점과 두 기준점 정합. 지도·도면 축척 차이와 미실측 상태 기록.
- 브라우저 검증: 실제 도로 → 너나들이 진입 → 주차구역 앞 차로까지 도착. 추가된 전진 주차 계산은 소형차 예시 제원에서 P2·P3 구획 내부까지 연결하며, 실제 설치된 EV나 현장 주행으로 집계하지 않습니다. EV·집결지의 전체 경로와 화재 우회/차단은 합성 시나리오에서 검증.
- 네이버 좌표와 같은 서울시 페이지의 외관 사진, OSM 윤곽, 공개 입주표 4개 주거층을 외관 모델에 반영. 사진측량 복원이 아님.
- `reports/report_2026-09-21T15-57-34-751Z.html`: 단위 24, 브라우저/골든 8, 라우터 21 통과. 문장 커버리지 98.81%. 실제 생성·비교 결과이며 골든 업데이트 옵션 없이 실행.
- 기존 `http://localhost:5190/api/apps`에서 `/map_new/` 등록 확인. 같은 서버에서 최신 보고서 JSON 조회 성공. 루트 파크의 입구·검증 패널 브라우저 확인.

**전체 목표는 미완료:** Google 실제 인증·3D 지도 표시, 실제 시설의 EV·지상 대피 연결, 의미가 없는 이미지에서의 전 과정 자동 의미 추출은 아직 증거가 부족하다. 이 항목들은 단위 테스트가 통과했다는 이유로 완료 처리하지 않는다.

## 이번 확장의 확인 범위

- 전체 63장에 Python 회색조·대비 보정·이진화와 374개 겹침 타일 분석을 적용했습니다. 원본과 선의 좌표를 확인할 수 있습니다. 도서당 안내 자료 3장·달리 및 코이노니아 입체도 4장은 평면 벽체 변환에서 제외하며 자료 수에만 포함합니다.

- 공개 기지국은 44개 장소 주변 자료를 보관합니다. 같은 무선국 중복을 제거한 기록은 1,925개입니다. 실측 수신값은 제공되지 않았으며 임의 생성하지 않습니다.
- 원본 주차 구획은 4장에 187면, 공간 오브젝트는 6장에 183개, OCR은 63장에 총 1,506개입니다. 도면 정보 창과 JSON 내보내기로 확인합니다.
- 모든 63장의 의미 구조가 완성됐다는 의미는 아닙니다. B2의 주차면은 도면 기재 121면 중 101면을 검토했습니다. 문 위치·안전 출구·전원 용량·배선·현재 운영은 원본만으로 확정하지 않습니다.
- 최신 확장 결과는 루트 `reports/latest.json`이 가리키는 회차에서 확인합니다. 이전 회차의 24/8개 테스트 통과 기록은 확장 전 결과입니다.

- 발행처 고해상도 원본 31장을 확보했으며 원본 파일·페이지 해시와 이전 이미지 이력을 보존합니다. OCR 1,506개는 해당 원본 해시와 일치합니다.
- 반복 구획선에서 자동 검출한 후보 194개와 기존 검토 구획에 대응한 98개를 별도 표시합니다. 실제 주차면·장애인 구획·충전기 점수·경로에는 자동 승격하지 않습니다.
- 대천항 도면 범례와 평면 위치를 대조한 47개 공간 오브젝트를 추가했습니다. 높이·마감·계단 단수는 미리보기 가정입니다.

### 대천항 주차장 길찾기

대천항 1층 원본에서 일반 주차면 50곳·장애인 2곳을 대조했습니다. 북측·서측 차로의 진입점부터 일반 주차면 **앞 차로**까지 차량·보행 경로를 제공합니다. 화면의 주차면을 클릭하거나 목적지에서 선택하고 안내를 시작합니다. 1·3인칭, 재생 속도와 도착 표시를 사용할 수 있습니다. 이 도면의 구획 내부 전진·후진 주차 조작은 자동 안내에 포함하지 않습니다.

원본 벽 62개와 유리면 10개를 주석하여 문 개구부를 보존했고, 도로·차양 점선을 벽체에서 제외했습니다. 축척은 원본의 10m 막대(274px)로 맞췄습니다. 각 벽의 시작·끝 좌표, 길이·두께·가정 높이를 도면 정보에서 확인할 수 있습니다. 현장 측량·현재 출입 허용은 별도 확인 대상입니다. 차량 충돌 검사는 경로 전체의 벽·기둥과 차체를 확인하고, 잘게 나뉜 같은 차로의 그래프 구간 경계도 연속된 차로로 처리합니다.

- 동탄 1층: 치수선 축척 보정, 벽·난간 48개, 오브젝트 23개. 일반 13면 앞과 서측 출구까지 구역별 일방통행 안내를 추가했습니다. 장애인 12면·전용 6면을 보호하고, 동서측을 잇는 미검토 램프나 중앙 OPEN 공간의 경로는 생성하지 않습니다.
